## 先搞懂：静态码和动态码，印之前必须分清

这是整篇最重要的一节，决定你印出去的东西会不会突然变砖。

- **静态码：** 网址直接写进图案里，中间没有人。印出去就改不了地址，但谁也关不掉它——只要你自己的网址还活着，码就能扫。
- **动态码：** 图案里装的是生成器公司的短链（比如 qrco.de），扫码先到它的服务器，再跳转到你的页面。好处是能改地址、能数扫码量；代价是试用一到期、订阅一停，服务器就不再转发，**所有印出去的码同时失效**——菜单、名片、包装、招牌一起死。
- **印之前自查，一秒钟：** 手机相机对准码，先看地址再点。显示你自己的网址，就是静态；显示生成器公司的短链，就是动态。

## 步骤一：QRCode Monkey——定制最全，下载后弹注册窗但能关

打开 https://www.qrcode-monkey.com/ ，页面就是生成器，不用注册、不用登录。顶部有 14 种内容类型：URL、Text、Email、Phone、SMS、vCard、meCard、Location、Facebook、Twitter、YouTube、WiFi、Event、Bitcoin。

![QRCode Monkey 生成器页面](img/2026-11-25-免费二维码三家横评/step1.png)

在 URL 框粘贴测试链接，点“Create QR Code”，预览马上生成。清晰度滑块默认 1000 x 1000 Px，拖到最右是最大值 2000 x 2000 Px，重新生成后点“Download PNG”。我下了两次：一次默认黑白，一次把前景色改成 #0066CC 蓝色（展开“SET COLORS”改的，预览立刻变蓝），两次都成功下载。

下到的文件实测数据：

- 黑白版：PNG，**2277 x 2277 像素，21,722 字节**（滑块标的是 2000 上限，实际文件是 2277，含留白边距）。
- 蓝色版：PNG，**2277 x 2277 像素，21,792 字节**。
- 每次下载后都会弹出同一个 QRCG by Bitly 注册推广窗，标题是“QR Code Generator PRO”，按钮“FREE SIGN UP”——关掉就能继续，没有强制注册。
- 导出按钮并列提供 Download PNG、.SVG、.PDF*、.EPS*（* 号注明“no support for color gradients”，即 PDF 和 EPS 不支持渐变色）。**本次只实际下载验证了 PNG，SVG、PDF、EPS 没有逐个下载验证。**

“Statistics and Editability”（统计与可编辑）开关默认是 OFF。点它不会开启，而是弹出同一个 PRO 注册窗，文案是让你注册看扫码统计。页面正文也写明了：“The created static QR code is 100% free but if you need scan statistics, flexible editability and more features then have a look at our QR Code Generator for professionals.”——免费码是静态码，统计和可编辑属于付费功能。

官网 FAQ 原话：生成的码“do not expire and will work forever”，“There is no limit and the created QR code will work forever”，且明确可用于商业用途。Logo 可以自己上传（png、jpg、gif、svg，最大 2 MB）或从图库选，纠错率最高 30%，也就是说码面最多 30% 被 logo 盖住还能扫。

## 步骤二：goQR.me——最干净，全程连注册提示都没有

打开 https://goqr.me/ ，点网址类型图标，输入测试链接，预览自动生成，不用点生成按钮。点预览下方的“Download”打开下载对话框。

![goQR.me 生成器页面](img/2026-11-25-免费二维码三家横评/step2.png)

下载对话框里实际提供的按钮只有四种：**SVG、EPS、PNG、JPEG**，没有见到 GIF 按钮——但页面正文另称支持“PNG, GIF, JPEG (incl. high resolution), PDF, SVG, EPS”，两者不完全一致，写稿时以对话框实际按钮为准。尺寸滑块默认 400，拖到最右是最大值 1000（即 1000 像素），本次就是按 1000 下载的。

## 步骤三：QR Code Generator——默认动态码，免费 JPG 藏在开关后面

打开 https://www.qr-code-generator.com/ ，首页点免费静态码列表里的“Website”，进入静态网址码页面（标题是“Generate QR Code for URL for Free”）。输入测试链接，预览自动生成——但先别急着下载，看两处地方：

![QR Code Generator 静态码页面：Scan tracking 默认开启](img/2026-11-25-免费二维码三家横评/step3.png)

第一，**“Scan tracking”开关默认就是开着的（蓝色、已勾选）。** 只要它开着，预览上方就会出现粉色标签“Dynamic QR Code”，下方还挂着 Total scans、Unique scans、Top location 三项统计占位（灰色占位条，没有数字）。也就是说，虽然页面标题写着 Static URL，但默认给你的其实是动态码。把开关关掉，粉色标签和统计占位立刻消失，只剩二维码预览，这时才是静态码。

该站自己的定义也写得很清楚：静态码生成后不能编辑、扫码无法追踪；动态码则可以随时改内容、改链接、修错字，还能统计扫码量和地点。动态码的代价就是它要经过该站服务器中转——而这正是后面会出事的地方。

第二，**下载格式。** 主按钮是“DOWNLOAD JPG”。关掉追踪之后点它，JPG 成功下载：**300 x 300 像素，22,222 字节**，本地解码指向原网址（静态码，验证通过）；下载的同时会弹出注册推广窗，关掉即可。但点下拉菜单里的“Download PNG”，直接弹出注册窗“Sign up to download your QR Code”，没有下载任何文件。官网 FAQ 原文与此一致：免注册只能下高清 JPG；要 PNG、SVG、EPS 必须注册账号，而且 EPS 只有黑白、没有设计样式。

而保持默认状态（追踪开启）点 DOWNLOAD JPG 时，两次尝试都只弹出注册窗“Sign up to download your QR Code”，**没有任何文件下载**。也就是说：默认动态码在不注册的情况下根本拿不到文件；免费 JPG 只属于关掉追踪之后的静态码。

## 结论：分别适合谁

- **印名片、菜单、包装、招牌，要矢量文件交给印刷厂：选 QRCode Monkey。** 免费档就有 SVG/PDF/EPS，logo 和改色全开，码永不过期。忍受一下每次下载后弹一次注册窗（关掉就行），或者直接当它不存在。
- **随手要一个码、要嵌进自己程序批量生成：选 goQR.me。** 全程最干净，没有任何注册提示，还有免费 API 一条请求出图。代价是 PNG 最大只有 1000 像素，定制只有改尺寸，logo、改色、统计一概没有。
- **QR Code Generator：只适合已经打算付费、确实需要改地址和扫码统计的人。** 免费档的正确用法是：先把 Scan tracking 关掉，再下 JPG；默认状态不要直接印。它的 14 天试用期一过，试用期内做的动态码会被停用，扫码跳到服务页——印之前先想好，14 天后你还愿不愿意每年付 $119.88。
- **不适用人群：** 需要动态码但不想付费的人，三家免费档都给不了（Monkey 和 goQR 根本没有动态码，QRCG 的动态码要付费）。真需要改地址又不想付年费，有个土办法：静态码指向你自己网站上的一个固定页面，以后改地址只改自己站内的跳转，码不用重印。

## 注意事项、费用、坑点

- **费用：0 美元。** 三家实测全程没有付费墙，没有要求输入邮箱或信用卡。
- **最大的坑：默认动态码。** QR Code Generator 的 Scan tracking 默认开启，页面标题写 Static URL，实际给的是动态码。第三方整理的用户投诉里，试用结束动态码失效是头号问题：该站 Trustpilot 评分 1.5/5（9,200 多条评价，截至 2026 年 3 月）；帮助中心原话是试用结束动态码“are deactivated and point to a service page rather than the original destination”。付费后取消也一样：动态码在已付费期加 30 天之后同样停用。印了几千张名片才发现码死了，返工成本比年费贵得多。
- **印之前先扫码看地址。** 手机相机对准码，**先看地址再点**：显示你自己的网址就是静态，显示 qrco.de、l.ead.me 这类生成器短链就是动态。已经印出去的码也可以这样自查。
- **Monkey 的 PDF 和 EPS 不带设计。** 官网写明 logo 和设计选项目前只在 PNG 和 SVG 里保留，PDF 和 EPS 只有经典黑白码；渐变色在 PDF/EPS 里也不支持。要带 logo 的印刷稿，导出选 SVG。
- **goQR 对话框与页面文字不一致。** 页面正文列了 GIF 和 PDF，实际下载对话框只有 SVG、EPS、PNG、JPEG 四个按钮；要 GIF 或 PDF 得换别的工具。
- **颜色对比度决定能不能扫。** 前景一定要比背景深得多，浅色字、黄色底、金色字印出来经常扫不出来；Monkey 自己也会在对比度不够时弹警告。logo 别盖超过码面的 30%，否则纠错也救不回来。
- **静态码印出去改不了地址。** 网址先定死再印；菜单、价格页这种可能换地址的，宁可先在自己站内做个固定短链页面，码指向它，以后只改站内跳转。
- **其他家的免费动态码也有代价（第三方横评说法，本次未实测）：** 比如 ME-QR 的免费动态码扫码时会先给扫码的人看广告；QRStuff 免费账号的动态码 30 天过期、每月 50 次扫码上限。动态码没有白吃的午餐，免费档总有一处在收费——要么是钱，要么是扫码人的注意力，要么是有效期。
- **顺带一提（第三方横评说法，本次未实测）：** Chrome 和 Edge 浏览器自带生成二维码的功能，打开页面点分享就能出码，不用注册，适合临时给对面的人扫一下；但它只有 PNG、不能改色加 logo，不适合印刷。
