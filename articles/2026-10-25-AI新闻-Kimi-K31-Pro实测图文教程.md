# 上手实测 Kimi K3.1 Pro：1M 上下文 + 3D Make，今天就能跑的三种入口

**一句话导读：** Moonshot 在 2026 年 10 月 23 日（北京时间 10 月 24 日）发布 K3.1 Pro：1M 上下文、Terminal-Bench 4.0 65.7%、3D Make 上线；但先说清楚——这不是免费薅：Kimi Code 侧需 Plus 及以上会员，API 按量付费，完整权重 11 月 4 日前才发布。

## 前置条件

- 任选一个入口：kimi.ai 网页 / Kimi App / Kimi Work 桌面端（3.1.0+）/ Kimi Code / Kimi API
- API 路线需要一个 Kimi API 账号并充值（第三方转述称最低充值 $1，未在官方页直接核实）
- 不需要亲赴海外；国际用户注册页是否需要中国手机号未核实（见注意事项）

## 步骤 1：读官方公告，确认这是什么模型

打开官方博客 https://www.kimi.ai/blog/kimi-k3-1-pro 。官方原话要点：

- Kimi K3.1 Pro 是 K3.1 系列首款、“最强 3T 级开放权重模型”，1M token 上下文；同发 Highspeed 版，快 2–3 倍；
- 当日上线 Kimi.ai、Kimi Work、Kimi Code、Kimi API；完整权重 2026 年 11 月 4 日前发布；
- Terminal-Bench 4.0 得分 65.7%，高于 GPT-6 Astra（58.2%）、略低于 Claude Opus 5.5（66.4%）；
- BenchCAD 带工具 92.7%，接近 Claude Opus 5.5（96.2%）与 GPT-6 Astra（95.9%）；
- 内部幻觉测试 claim-level 错误率从 K3 的 23.4% 降至 8.3%（内部基准，不是日常使用错误率）。

![Kimi 官方公告页：K3.1 Pro 介绍、基准与可用性](img/2026-10-25-kimi-k31/step1.png)

## 步骤 2：三种入口，今天就能跑

1. **网页 / App 对话：** 打开 kimi.ai 或 Kimi App，模型选择器里选 K3.1 Pro，直接对话；1M 上下文适合丢长文档、长代码库、长财报进去做跨文档核对。
2. **Kimi Work 桌面端：** 下载最新 Kimi Work 桌面应用（3.1.0 或更高，Windows 与 Apple silicon Mac），在里面用 K3.1 Pro 做文档、表格、PPT 类的长程任务。
3. **Kimi Code 写代码：** 跑 Kimi Code，用 `/model` 命令选 `k3.1-pro`。第三方口径（unite.ai 等 2026-10-23 报道）：新会员体系下 `k3.1-pro` 需 Plus 及以上，1M 上下文需 Pro 及以上，Highspeed 需 Pro 及以上；仅支持思考模式，`reasoning_effort` 为 low / high / max（默认 max）；中途换模型会损质量，建议开新会话；企业版默认关闭，需管理员开启。以上会员门槛为第三方口径，未在官方博客正文核实，动手时以 Kimi Code 内实际显示为准。

## 步骤 3：走 API，模型 ID 与定价口径

打开 Kimi API 平台 https://platform.kimi.ai ，选模型 `kimi-k3.1-pro` 或 `kimi-k3.1-pro-highspeed`。API 端点与 OpenAI 兼容：`https://api.moonshot.ai/v1`。

定价为第三方口径（benchdict 等 2026-10-23 报道，未在官方页直接核实）：Pro $2 / $10 每百万 input / output token，缓存命中 $0.20；Highspeed $4 / $20；比 K3（$3 / $15）降约三分之一。动手前以平台实际价格页为准。

![Kimi API 平台首页：K3.1 Pro 已上线横幅与 API 入口](img/2026-10-25-kimi-k31/step2.png)

## 步骤 4：试 3D Make，在线生成可打印的 3D 模型

3D Make 已在 kimi.ai 和 Kimi App 上线：输入文字描述、草图或参考图，在线预览与编辑 3D 模型，可下载用于 3D 打印，或导出视频 / Live Photo 分享。官方博客“3D Modeling and Design”一节原话就是这个功能；但 3D Make 是否全量免费、有无导出次数限制，官方博客没有给额度——未验证，不要写成无限免费。

![kimi.ai 首页：模型选择器与 3D Make 入口](img/2026-10-25-kimi-k31/step3.png)

## 注意事项、费用、坑点

- **费用（先说清楚，不是免费薅）：** Kimi Code 侧 `k3.1-pro` 需 Plus 及以上会员（第三方口径）；API 按量付费；没有可宣称的免费额度——第三方称“Kimi App 有免费层”的说法与 Kimi Code 会员门槛冲突，以付费门槛为准，不写免费。
- **会员按积分 / 额度计量，不是无限次：** SCMP 实测报道称附赠会员约 6 轮改稿后即提示额度耗尽（第三方报道）；K3 上线 48 小时内（2026 年 7 月 20 日）曾因需求过载暂停新订阅，后拆分为两档会员——高峰期可能再次限流或排队。
- **11 月 4 日权重只是承诺：** 许可证至今未公布；K3 权重约 1.4TB 量级为第三方说法，普通电脑无法本地跑——不要承诺“11 月 4 日下载即免费本地用”。
- **日期口径：** Moonshot 博客与 LinkedIn 时间戳为 2026 年 10 月 23 日（UTC），PANews / CGTN 按北京时间写 10 月 24 日，是同一事件的时区差，本文统一写“2026 年 10 月 23 日（北京时间 10 月 24 日）发布”。
- **未验证项（不要当成事实写）：** Kimi 免费层对 K3.1 Pro 的具体可用性与额度；会员月费具体美元价（第三方旧档称 Plus $19 起，但新旧体系名称已变）；API 最低充值 $1（仅第三方转述）；11 月 4 日权重的许可证、体积、下载渠道；国际用户注册 kimi.ai / platform.kimi.ai 是否需要中国手机号或仅邮箱即可；3D Make 的导出次数限制。
- **安全口径（官方自述）：** 为开放权重发布，官方称已从中训和 RL 两阶段剔除网络攻击相关数据；内部 xdev-bench-hard pass@3 从未清洗检查点的 90.5% 降至正式版 81.0%，仍高于 K3 的 33.3%。
- **与往期不重复：** 10 月 20 日 MiMo-V2.5 下线、10 月 22 日 OpenAI 模型登陆 Google Cloud 均与本篇不同；Kimi K3.1 Pro 未在往期出现。
