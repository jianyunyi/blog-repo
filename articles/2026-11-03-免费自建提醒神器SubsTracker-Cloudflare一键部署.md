# 订阅续费、生日纪念日总忘？免费自建一个提醒神器 SubsTracker：Cloudflare 一键部署保姆级教程

![图1](img/2026-11-03-substracker/img1.png)
SubsTracker 是开源的订阅管理与到期提醒系统，跑在 Cloudflare Workers + KV 上，免费额度完全够用：把订阅、会员、生日、纪念日录进去，到期前 7 天、3 天、1 天和当天主动推送到手机，支持农历提醒和 Telegram、Bark 等 11 种通知渠道；部署 3 分钟。

底本：YouTube 频道「半路极客」2026 年 11 月 3 日视频；本文步骤已与项目官方仓库 README 逐项交叉核实，核实日期 2026 年 11 月 3 日。
先说一个很多人都中过招的场景：某天打开账单，发现某个视频会员又自动续费了一个月——你明明三个月前就想取消了，就是忘了它的到期日。再往大里说：家人生日、结婚纪念日、域名到期、服务器续费、电话卡保号……现代人要记的「日子」越来越多，全靠脑子，翻车只是时间问题。
今天这个工具就是来解决这件事的：**SubsTracker**，一个开源免费的订阅管理与到期提醒系统。把它部署到 Cloudflare 上（免费额度完全够用），所有订阅、会员、生日、纪念日都录进去，到期之前它主动推送到你的手机——该续的续、该取消的取消、该祝福的祝福，一个都不漏。
## 它是什么，凭什么值得自己搭一个
SubsTracker 跑在 Cloudflare Workers + KV 上，是一个轻量级的网页应用：浏览器里打开就能管理，不用装 App，不用买服务器。项目在 GitHub 开源（MIT 协议），目前约 3.2k Star、2.6k Fork，维护活跃。它能做的事包括：
· **订阅管理**：名称、金额、周期、到期日、分类，支持多币种和支出统计；

· **多规则提醒**：每条订阅可设多条规则，默认预设是到期前 7 天、3 天、1 天 + 到期当天；

· **生日/纪念日**：支持**农历周期**，家里老人按农历过的生日也能准确提醒；

· **11 种通知渠道**：Telegram、Bark、企业微信、ntfy、邮件、Server 酱、PushPlus、Webhook 等，总有一款能推到你的手机上；

· **发送可查**：自带通知历史和调度日志，发没发、为什么没发，后台看得一清二楚。
说句实话先放前面：视频标题里的「3 分钟」指的是部署动作本身。算上创建令牌、配通知、加订阅，第一次完整走下来大约一刻钟。一次搭好，长期省心，这笔时间账还是划算的。
## 开始之前，准备这三样
1. 一个 **Cloudflare 账号**（免费注册）；

2. 一个 **GitHub 账号**（用来 Fork 项目并运行自动部署）；

3. 想好用哪种方式收通知：iPhone 用户推荐 **Bark**（系统级推送，最稳）；微信重度用户可以用**企业微信群机器人**。两者也可以都配。
可选：一个自己的域名。没有也能用，Cloudflare 会给一个免费的 workers.dev 地址，想绑自己的域名后面有一步专门说。
## 第一步：创建 Cloudflare API 令牌
这是整个部署的「钥匙」，GitHub 上的自动部署要用它来操作你的 Cloudflare 账号。
1. 登录 Cloudflare，进入右上角头像 → **My Profile → API Tokens**（也可以直接在控制台里找 API 令牌）；

2. 点 **Create Token → Create Custom Token**；

3. 权限给两项：**Workers 的编辑权限** + **KV 存储的编辑权限**（视频里演示的也是这两项，够用且不过度授权）；

4. 创建后把令牌**复制保存好**——它只完整显示这一次，第三步要用。提醒一句：这个令牌等于你 Cloudflare 账号的一把钥匙，不要发给任何人、不要截图外传。
## 第二步：Fork 项目，填好变量，一键部署
1. 打开项目仓库 **github.com/wangwangit/SubsTracker**，点右上角 **Fork**，把项目复制到你自己的 GitHub 账号下；

2. 进入你 Fork 后的仓库，打开 **Settings → Secrets and variables → Actions**，新增一条 Secret：

　· 名称：**CLOUDFLARE_API_TOKEN**，值：第一步创建的令牌；

　· **CLOUDFLARE_ACCOUNT_ID** 是可选项（在 Cloudflare 控制台首页右侧能看到自己的 Account ID），填上部署更稳，不填通常也能跑；

3. 打开仓库的 **Actions** 页，选 **Deploy** 工作流，点 **Run workflow** 手动运行一次（之后每次向主分支推送也会自动部署）；

4. 等工作流跑完变绿勾，部署就完成了。你的系统地址形如 **https://subscription-manager.你的子域.workers.dev**，在 Cloudflare 控制台的 Workers 列表里也能找到它。
## 第三步：登录，第一件事——改密码
打开你的系统地址，用默认账号登录：
用户名：**admin**　密码：**password**
**登录后立刻进「系统配置」把密码改掉。**这不是客气话：默认密码是公开写在项目说明里的，你的系统又暴露在公网上，不改等于大门敞开，谁都能进来接管。这一步做完，再继续下面的配置。
## 第四步（可选）：绑定自己的域名
不喜欢 workers.dev 的长地址，可以绑自己的域名：在 Cloudflare 控制台进入这个 Worker → **设置 → 域和路由（自定义域）**，添加你托管在 Cloudflare 的域名即可。视频里这一步在部署后完成，进系统配置之前顺手就办了。没有域名直接跳过，不影响任何功能。
## 第五步：第一次必做的基础配置
进「系统配置」，按顺序把这两项设好，后面少踩很多坑：
**1. 时区**：选 **Asia/Shanghai**（北京时间）。所有「还有几天到期」「几点发通知」都以这个时区为准，设错了提醒全乱套。
**2. 允许发送的小时**：这是通知的「发送窗口」。系统每小时整点检查一次，但只在你允许的小时里才真的发。比如填 **08**，就是每天只在早上 8 点那一小时发；填 **08, 20** 就是早晚各一个窗口；留空或填 * 则是每个整点都可以发。建议先填 **08**，早上起来集中看一眼，最不打扰人。
## 第六步：配置通知（Bark + 企业微信）
在「系统配置」的通知渠道区，至少打开一种，并逐项点「测试」确认能收到——这一步视频里用的是 Bark + 企业微信的组合，一个推手机、一个进微信，双保险：
**Bark（iPhone）**：在 App Store 装好 Bark App，打开后它会给你一串 **Device Key**，填进系统配置的 Bark 栏，保存后点「测试 Bark 通知」，手机立刻弹出推送就是通了。
**企业微信**：在企业微信里建一个群（或用现有群）→ 群设置 → 群机器人 → 添加机器人，复制它的 **Webhook 地址**，填进系统配置的企业微信栏，同样点测试，群里收到消息即成功。
其他渠道（Telegram、ntfy、邮件等）配置思路都一样：勾选渠道 → 填 Token/地址 → 测试到成功为止。**没测通就往下走，是后面「为什么没收到通知」的头号原因。**
## 第七步：加上你的第一条订阅
进「订阅列表」→ 添加订阅，照着视频里的两个演示各来一条：
**演示一：付费订阅。**填名称（比如某个视频会员）、金额、计费周期、到期日，提醒规则直接用默认预设「7 / 3 / 1 天 + 到期当天」。保存。这类订阅续费前你会收到三次提醒，足够你决定续还是取消，再也不会被「忘了取消」偷走一个月会员费。
**演示二：生日提醒。**名称填「妈妈生日」，周期选**农历**、一年，把农历生日填上。以后每年提前 7 天、3 天、1 天都会提醒你，订蛋糕、备礼物的时间全留出来了。结婚纪念日、域名到期、电话卡保号这类「周期性日子」都可以照这个套路加。
补两个实用细节：续费后点「续订」能把到期日往后延并记一笔支付记录；一批同类订阅（比如几张保号卡）可以用「克隆」复制一条改个名，不用从头填。
## 用之前，必须搞懂的三个机制
这部分是官方 README 特别强调、也最容易被误解的地方，先看懂能省掉一半「为什么没提醒我」的困惑：
**1. 「到期前 N 天」只发一次。**它的意思是「剩余天数正好等于 N 的那一天发一次」，不是从第 N 天起天天发。所以想要 7、3、1、当天都有提醒，就用预设的多条规则，而不是指望一条「提前 7 天」连发一周。
**2. 「允许发送的小时」是窗口，不是次数。**系统每小时整点检查一次，落在窗口外就跳过（通知历史里会写「不在允许发送的小时」，这是正常跳过，不是故障）；同一条规则在同一天命中后只发一次，早晚两个窗口不会重复发。
**3. 没收到通知，先查「通知历史」。**里面会写明是发送成功、渠道报错，还是被跳过以及跳过原因。按这个顺序排查：渠道是否启用且测试通过 → 当前小时是否在发送窗口内 → 时区是否正确 → 订阅是否启用、今天是否正好命中规则。九成问题都能在这里找到答案。
## 费用、安全与备份
**费用**：Cloudflare 免费套餐对个人量级的提醒完全够用——一个提醒系统每小时才运行一次，Workers 和 KV 的免费额度根本用不完，域名也是可选项。整个方案的真实成本是 0 元。
**安全**：除了前面说的立刻改掉默认密码，再记住两条：API 令牌、Bark Key 这类密钥不要提交进 Git、不要发给别人；万一令牌泄露，去 Cloudflare 后台把它删掉重建即可。
**备份**：系统配置最下方可以**导出备份**（JSON 文件）。换 Cloudflare 账号或重装时，部署好新系统再导入即可。升级或迁移之前，先导出一份存好，稳妥。
## 写在最后
提醒类工具的价值不在功能多炫，而在于它能不能「一次配置、长期可靠」。SubsTracker 的好处恰好在这里：数据在你自己的 Cloudflare 账号里，规则透明、日志可查，订阅和生日用同一套系统管起来。花一刻钟搭好，往后的每一次到期，它都比你先想起来。
