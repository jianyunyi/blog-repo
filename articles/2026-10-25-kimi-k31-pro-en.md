# Hands-On with Kimi K3.1 Pro: 1M Context, 3D Make, and Three Ways to Try It Today

**One-line summary:** Moonshot released K3.1 Pro on October 23, 2026 (October 24 in Beijing time): a 1M-token context window, 65.7% on Terminal-Bench 4.0, and 3D Make live — but let's be clear up front: this is not a free giveaway. Kimi Code access needs a Plus-tier membership or higher, the API is pay-as-you-go, and the full weights don't arrive until November 4.

## What You Need

- Any one entry point: kimi.ai on the web / the Kimi app / Kimi Work desktop (3.1.0+) / Kimi Code / the Kimi API
- For the API route, a Kimi API account with credit (third-party reports mention a $1 minimum top-up — not confirmed on an official page)
- No travel needed. Whether international signup requires a Chinese phone number or just an email is unverified (see the caveats)

## Step 1: Read the Official Announcement to See What This Model Is

Open the official blog, https://www.kimi.ai/blog/kimi-k3-1-pro . The official points:

- Kimi K3.1 Pro is the first model in the new K3.1 series and the "most capable 3T-class open-weight model to date," with a 1-million-token context window; a Highspeed variant runs 2–3× faster;
- Available the same day on Kimi.ai, Kimi Work, Kimi Code, and the Kimi API; full model weights by November 4, 2026;
- Terminal-Bench 4.0 score of 65.7%, ahead of GPT-6 Astra (58.2%) and just behind Claude Opus 5.5 (66.4%);
- BenchCAD with tools: 92.7%, close to Claude Opus 5.5 (96.2%) and GPT-6 Astra (95.9%);
- Internal hallucination test: claim-level error rate down from 23.4% (K3) to 8.3% (internal benchmark, not an everyday error rate).

## Step 2: Three Entry Points You Can Use Today

1. **Web / app chat:** Open kimi.ai or the Kimi app, pick K3.1 Pro in the model selector, and start chatting. The 1M context fits long documents, large codebases, and long financial reports for cross-document checks.
2. **Kimi Work desktop:** Download the latest Kimi Work desktop app (version 3.1.0 or later, Windows and Apple silicon Macs) and use K3.1 Pro for long document, spreadsheet, and deck work.
3. **Kimi Code for coding:** Run Kimi Code and select K3.1 Pro with the `/model` command. Third-party reports (unite.ai and others, October 23, 2026) describe the new membership tiers: `k3.1-pro` needs Plus or higher, 1M context needs Pro or higher, Highspeed needs Pro or higher; only thinking mode is supported, with `reasoning_effort` low / high / max (default max); switching models mid-session hurts quality, so start a new session; the enterprise edition is off by default and needs an admin to enable it. These tier details are third-party reports, not confirmed in the official blog text — go by what Kimi Code actually shows.

## Step 3: Use the API — Model IDs and Reported Pricing

Open the Kimi API platform, https://platform.kimi.ai , and select `kimi-k3.1-pro` or `kimi-k3.1-pro-highspeed`. The API is OpenAI-compatible at `https://api.moonshot.ai/v1`.

Pricing is third-party reporting (benchdict and others, October 23, 2026 — not confirmed on an official page): Pro at $2 / $10 per million input / output tokens, $0.20 on cache hits; Highspeed at $4 / $20; about a third cheaper than K3 ($3 / $15). Check the platform's actual pricing page before spending.

## Step 4: Try 3D Make — Generate Printable 3D Models Online

3D Make is live on kimi.ai and the Kimi app: from a text brief, sketch, or reference image, preview and edit 3D models online, download them ready for 3D printing, or export them as videos or Live Photos. That's the official blog's "3D Modeling and Design" section. Whether 3D Make is fully free, or has export limits, is not stated in the official blog — unverified, so don't describe it as unlimited free.

## Costs, Limits, and Pitfalls

- **Cost — stated plainly, not a freebie:** Kimi Code access to `k3.1-pro` needs a Plus-tier membership or higher (third-party reports); the API is pay-as-you-go. There is no advertised free tier to claim — third-party claims of a "free tier on the Kimi app" conflict with the Kimi Code membership requirement, so this article goes with the paid requirement, not the free claim.
- **Memberships are metered by credits, not unlimited:** SCMP's hands-on report described a complimentary membership prompting for top-up after about six revision rounds (third-party report). When K3 launched, demand overload paused new subscriptions within 48 hours (July 20, 2026) before the membership split into two tiers — expect throttling or queues again at peak times.
- **November 4 weights are a promise, not a delivery:** The license is still unpublished, and the weight size is in the multi-terabyte class by third-party accounts (K3 was about 1.4TB) — don't promise "download on November 4 and run it free locally."
- **Date note:** The Moonshot blog and LinkedIn timestamps are October 23, 2026 (UTC); PANews and CGTN report October 24 in Beijing time. Same event, timezone difference — this article writes "October 23, 2026 (October 24 Beijing time)."
- **Unverified items — don't treat them as facts:** free-tier availability and quota for K3.1 Pro; exact membership monthly prices in USD (older third-party docs say Plus from $19, but the tier names have since changed); the $1 API minimum top-up (third-party restatement only); the November 4 weights' license, size, and download channel; whether international signup on kimi.ai / platform.kimi.ai needs a Chinese phone number or just an email; 3D Make export limits.
- **Safety note (official self-report):** For the open-weight release, Moonshot says cyber-related data was removed from both mid-training and RL stages; its internal xdev-bench-hard pass@3 fell from 90.5% (unfiltered checkpoint) to 81.0% for the final model, still above K3's 33.3%.
- **No overlap with earlier editions:** October 20 covered MiMo-V2.5's sunset and October 22 covered OpenAI models on Google Cloud — both different from this article. Kimi K3.1 Pro has not appeared before.
