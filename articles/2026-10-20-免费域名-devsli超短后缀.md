# 又一个永久免费域名！devs.li 超短后缀，每人 5 个，三字母还能抢

好域名先拼手速：**DEVS.LI** 是一个面向开发者的免费子域名平台，后缀只有 6 个字符，你能拿到的是 **你的名字.devs.li** 这种超短域名。官方口径：**永久免费、无续费费用、每人默认 5 个**，专门给开源项目、个人作品集、小应用准备。视频作者今天实测时，**三字母前缀还有不少可注册**——这种短前缀在任何平台都是先到先得，看完就去查，别犹豫。

⚠️ **先把定位说清（重要）：**DEVS.LI 只支持在它家面板里加 A、AAAA、CNAME、TXT 记录和 URL 跳转，**不支持改 NS，devs.li 本身也不在公共后缀列表（PSL）上**，所以**没法像 DNSHE、DigitalPlat 那样把域名整站托管到 Cloudflare**。它的正确用法是给项目"挂一个好记的短域名"：指向 GitHub Pages、Vercel、Cloudflare Pages 或你自己的 VPS。想整站进 CF 的，继续看 DNSHE 那条线，两者不是一类东西。

## 一、它能干什么

- **指向静态托管**：CNAME 到 GitHub Pages（user.github.io）、Vercel（cname.vercel-dns.com）、Cloudflare Pages，平台会自动给你的 .devs.li 域名签发免费 SSL 证书（HTTPS 直接可用）
- **指向服务器**：A 记录（IPv4）/ AAAA 记录（IPv6）直连你的 VPS 或家里的机器
- **其他**：TXT 记录（做各种验证）、URL 跳转；解析走 Anycast 名称服务器，官方称生效很快，视频实测添加后马上就能查到
- **配额**：每人默认 5 个活跃子域名；做大开源项目不够用，可以联系团队申请扩容（站内有联系/工单入口）

## 二、注册四步（视频实测流程）

**第 1 步：查前缀。**打开 devs.li 首页，在搜索框输入你想要的前缀点查看。先查三字母、短单词这类，显示可用就别磨蹭。

**第 2 步：注册账号。**点"立即领取"会要求先建账号：填名字、邮箱、密码，勾选同意条款，点创建账号。

**第 3 步：邮箱验证。**去邮箱收验证码，填回页面，提示验证成功，账号就建好了。

**第 4 步：加解析记录。**验证完会弹出添加解析的界面（关掉也能之后在面板里点"创建域名"再加）。选记录类型填目标地址：静态站填 CNAME 目标，自有服务器填 A 记录的 IP，最后点 Provision Domain 提交，提示成功即完成。同一个账号重复这个流程，最多领 5 个。

💡 **填地址别学视频里的演示：**作者为了演示填的是必应等测试地址，还专门提醒 8.8.8.8 这类地址加不进去。你实际用的时候，填的一定要是**你自己项目的真实地址**（GitHub Pages 的 user.github.io、Vercel 的 cname.vercel-dns.com，或你 VPS 的公网 IP）。

## 三、怎么确认解析生效

平台自带 **DNS Lookup** 工具：输入你的完整域名点检查，能看到解析到的地址就是生效了；也可以用 itdog 这类第三方 DNS 查询站交叉验证。视频实测是添加后很快就解析成功。静态平台那边记得还要在 GitHub Pages / Vercel / CF Pages 的设置里把这个自定义域名绑上，并等 SSL 证书签发完，HTTPS 才算全线打通。
