# 免费智能体：n8n 自托管，一条 Docker 命令搭出 24 小时 AI 员工

> 一句话导读：不用买 Zapier、不用订阅 Coze 会员，一条 Docker 命令就在自己机器上跑起 n8n，工作流执行次数无上限，客服、订单通知、定时抓取全自动。

## 前置条件（需要什么）

- 一台能装 Docker 的机器：自己的电脑、VPS 都行（2C2G 就够跑，树莓派 4 都能带轻量任务）
- Docker（Linux 装 Docker Engine，Windows/Mac 装 Docker Desktop）
- 全程免费：n8n 社区版（Community Edition）自托管永久免费、执行次数无上限

## 分步骤

### 步骤 1：确认 n8n 是什么、免费在哪

n8n（读作 "n-eight-n"）是开源的可视化工作流自动化工具：拖拖拽拽把 App 连起来，"A 里发生一件事 → 自动在 B 里做一件事"。对标 Zapier（$30/月起），自托管版免费且不限执行次数。

![n8n 官网首页](img/2026-10-18-免费智能体-n8n/step1.png)

### 步骤 2：一条 Docker 命令启动

官方 Docker 安装文档给的标准命令（数据挂到 volume 里，重启不丢；`<YOUR_TIMEZONE>` 换成 `Asia/Shanghai`）：

```bash
docker volume create n8n_data
docker run -d --restart unless-stopped --name n8n -p 5678:5678 \
  -e GENERIC_TIMEZONE="Asia/Shanghai" \
  -e TZ="Asia/Shanghai" \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n
```

![n8n 官方 Docker 安装文档（Starting n8n）](img/2026-10-18-免费智能体-n8n/step2.png)

> 官方文档里这条命令现在挂着"已过时"提示，推荐改用 Docker Compose（长期跑更稳）；上面这条 `docker run` 照样能用，`-d --restart unless-stopped` 让它后台常驻、服务器重启自动回来。想上生产环境再去啃 Compose 版文档。

### 步骤 3：打开控制台，建本地管理员账号

浏览器打开 `http://localhost:5678`（VPS 上跑就把 5678 换成你的服务器 IP:5678），首次打开会让你创建一个 owner 账号——这是你自己这台实例的登录账号，不是 n8n 云账号。进去就是一块空白画布。

### 步骤 4：从模板库导入第一个工作流

别从零画：官网 `n8n.io/workflows/` 有上千个现成模板，复制 JSON → 控制台 Import，改改 key 就能用。给 AI 订阅店最实用的三个：

1. **订单通知**：Stripe/支付成功 webhook → Telegram/飞书推送"来单了"
2. **24 小时客服**：定时/触发式 FAQ 自动回复（10-14 的扣子客服篇是零代码版，n8n 是进阶版，数据全在自己手里）
3. **定时情报**：每天早 8 点抓 X/Reddit 出海帖 → 汇总推送到你手机

![n8n 工作流模板库](img/2026-10-18-免费智能体-n8n/step3.png)

### 步骤 5：点 Active，让它 7×24 小时自己跑

工作流右上角打开 **Active** 开关，n8n 就会按你设的定时/触发条件一直跑。容器加 `--restart unless-stopped`，服务器重启它自己回来。

## 注意事项、费用、坑点

- **费用**：自托管 $0；官方 n8n Cloud 有免费档（约 2500 次执行/月），想先体验不折腾服务器可以用它试水。
- **License 坑**：社区版是 fair-code（Sustainable Use License），个人/内部用随便跑，拿去商用转售工作流之前先读一遍 license 条款。
- **Webhook 公网回调**：微信/支付平台往 n8n 推消息时，需要公网能访问到它——本地跑的话配内网穿透，VPS 跑的话绑个域名 + HTTPS（可配 `WEBHOOK_URL` 环境变量）。
- **数据备份**：工作流和账号密码都存在 `/home/node/.n8n`（SQLite），备份这个目录就行，丢了加密 key 凭证就读不出来了。
- **前科排查**：n8n 是 2019 年起的老牌开源项目，无"突然收费/批量封号"黑历史；免费的是你自己搭的实例，不存在被官方掐断一说。
