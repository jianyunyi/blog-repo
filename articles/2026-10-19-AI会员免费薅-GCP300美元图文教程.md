# AI 会员免费薅（2）：Google Cloud $300 赠金——新用户 90 天云资源随便开

> 一句话导读：Google 给每个新用户发 $300 赠金、90 天有效期，能开虚拟机、跑 Cloud Run、无服务器容器全免费额度叠加。2026 年有个关键变化：3 月之后开的账单，赠金不能再直接抵 Gemini API 的账了——想薅 AI 得走 Vertex AI 这条路，下面讲清楚。

## 前置条件（需要什么）

- 一个没开通过 Google Cloud 的 Google 账号（每个自然人/支付方式限领一次）
- 一张有效的信用卡/借记卡（只做身份验证，不会自动扣费；可能有一笔预授权，1–14 天退回）
- 一个手机号（收验证码）

## 分步骤

### 步骤 1：打开 Google Cloud 免费页面，点 "Get started for free"

官网 cloud.google.com/free 就是领赠金的入口。页面上会同时讲两件事，别搞混：**$300 Welcome 赠金**（90 天有效）和 **Always Free**（每月重置的免费额度）。

![Google Cloud 免费页面：$300 赠金入口](img/2026-10-19-AI会员-GCP赠金/step1.png)

### 步骤 2：注册并绑卡验证身份

按页面流程：登录 Google 账号 → 填姓名地址 → 绑卡 → 手机验证。官方 FAQ 明确说了：要卡是为了验证你是真人、防止批量开号；**试用期内不会扣费**，真正的扣费只发生在你手动点"升级到付费账户"之后。不升级，$300 花完或 90 天到期，账单账户自动关闭，资源先停、30 天宽限期后删除。

### 步骤 3：建项目、确认账单挂的是赠金账户

进 Google Cloud Console，左上角项目下拉框 → **New Project** 建一个项目（比如起名 ai-playground）。然后去 **Billing** 确认项目挂在有 $300 赠金的账单账户下。2026 年 10 月的一篇实测帖把这套流程走了一遍，核心就这三步：领试用 → 建项目 → 确认账单挂载。

### 步骤 4：赠金能花在哪——以及 AI 的正确薅法

先看第三方整理的 $300 赠金限制表（2026 年 9 月更新），把坑都列出来了：

![Google Cloud $300 赠金限制说明](img/2026-10-19-AI会员-GCP赠金/step2.png)

赠金花法（按划算程度排）：

1. **Cloud Run**：每月 200 万次请求免费额度，赠金期内部署小应用基本不花钱，缩容到 0
2. **Compute Engine e2-micro**：Always Free 每月送一台（限美国三个区：us-west1/us-central1/us-east1），赠金可开更大机型练手
3. **BigQuery**：每月 1TB 查询免费，做数据分析够用
4. **Vertex AI**：想用赠金跑 Gemini 模型，**必须走 Vertex AI**（aiplatform 接口），不能走 AI Studio——这是 2026 年 3 月 2 日之后开的新账单的硬性规则，老攻略里"赠金直接调 Gemini API"已经过期了
5. **AI Studio 本身**：有独立的免费 tier（Gemini 2.5 Flash 等），不用赠金、不用绑卡，直接拿 Google 账号用

![Gemini 免费路线全览：各条路对比](img/2026-10-19-AI会员-GCP赠金/step3.png)

想把 $300 变成通用 AI 后端（给 OpenAI 兼容的工具用），2026-10-17 的实测帖给了个桥接方案：Vertex AI → OpenRouter BYOK（Bring Your Own Key），把 Vertex 的 endpoint 接进 OpenRouter 当自定义 key 用。

### 步骤 5：到期前二选一

- **升级付费账户**：保住资源和数据，未用完的赠金保留到 90 天期满，Always Free 额度继续有
- **不升级**：到期自动停服，30 天内可反悔升级，之后资源永久删除——重要数据提前备份

## 注意事项、费用、坑点

- **费用**：$300 赠金 + Always Free，90 天内 0 元；不手动升级绝不扣费，这是官方承诺。
- **最大坑（2026 新规）**：2026-03-02 之后开的账单，Welcome 赠金**不能**支付 Gemini API / AI Studio 的账单。看到 2026 年 3 月之前的老教程说"赠金随便调 Gemini"，直接忽略。
- **GPU 限制**：试用期内不能给 VM 加 GPU/TPU，想薅免费 GPU 去看 Kaggle / Colab 的免费 tier，别在这上面浪费时间。
- **Always Free 的 VM 只在美国三区**：孟买、新加坡等地开 VM 会从赠金里扣钱，90 天后按量计费。
- **长期免费风险**：赠金是限时促销不是永久免费，到期即止，不存在"悄悄收费"（不升级就不收费），但记得备份数据。
- **封号前科**：Google 对批量开号、同一支付方式多开审查较严，一人一号正常用没事。
