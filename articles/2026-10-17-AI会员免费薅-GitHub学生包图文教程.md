# GitHub 学生包白嫖 Copilot：无限代码补全免费领，但有个缩水要先说

**一句话导读**：认证成 GitHub 学生，免费拿 Copilot Student（含无限代码补全 + AI 额度）以及微软 365 AI、Notion 教育版等一堆开发工具福利，全程在线、学生证或在读证明就能办——但先说清楚：2026 年的现在，学生拿的是 Student 版不是 Pro 版，别被老教程忽悠了。

## 前置条件（需要什么）

1. 一个 GitHub 个人账号（年满 13 岁）
2. **在读学生身份**：高中 / 大学 / 职校 / 高职 / homeschool 都行，必须是在读
3. 材料二选一：
   - 学校官方邮箱（.edu 或学校域名），提前绑到 GitHub 账号并完成邮箱验证；或
   - 官方在读证明：带当前入学日期的学生证照片 / 课表 / 成绩单 / 在读证明信
4. GitHub 个人资料里填**与证件一致的真实姓名** + 一段简短 bio（社区实测：姓名对不上证件是常见被拒原因）
5. **不需要绑卡，不需要科学上网**（education.github.com、docs.github.com 国内可直连）

## 分步骤

### 步骤 1：先看福利总览，确认值得办

打开学生包福利总览页 https://education.github.com/pack，找到 GitHub Copilot 那张卡片。官方原话（2026-10-17 当天读取）：

![GitHub 学生包福利总览页，Copilot Student 卡片](img/2026-10-17-AI会员免费薅/step1.png)

卡片上写着：GitHub Copilot Student is available to verified students —— 包含**无限代码补全**（unlimited code completions）和一笔 GitHub AI Credits 额度，外加限量的 Chat / Agent 使用（只能自动选模型）。

同页还有其他 AI 福利：Microsoft 365（含 Copilot AI 助手、1TB 云存储）、Notion 教育计划（含额外 AI 回复额度）、Camber（AI 数据科学 agent，学生计划含每月 40 CPU 小时 + 5 GPU 小时 + 50 agent 消息）。

### 步骤 2：按官方文档准备材料

官方申请文档把资格和材料列得很细，先对照着准备，别裸交：

![GitHub 官方学生申请文档：资格与材料要求](img/2026-10-17-AI会员免费薅/step2.png)

要点：

- 必须是 degree- or diploma-granting program 的在读学生
- 证明材料要含**全名、学校名、能证明当前在读的日期**
- 部分学校系统强制要求用学校邮箱（"同校已有成功案例用邮箱验证，后续申请者也必须用邮箱"），先看你学校有没有这个规矩

### 步骤 3：去福利设置页提交申请，等审核

登录 GitHub 后打开 https://github.com/settings/education/benefits ，点 "Start an application"，按表单填学校信息、上传证明材料，提交。

审核实测：多数 **2–5 天**，高峰期 1–2 周，通过会收到邮件。注意一个细节：通过后福利不是立刻可用——状态页从绿标变紫标 "benefits are now available" 才算真正开通，中间有几天的延迟，急不得。

### 步骤 4：看懂你拿的是什么——Student / Pro / Free 对比

这一步最重要，直接决定你的预期。官方 Copilot 计划对比文档：

![Copilot 各计划官方对比：Free / Student / Pro](img/2026-10-17-AI会员免费薅/step3.png)

三档关系：Copilot Free（每月 2000 次补全）< **Copilot Student（无限补全、限量 Chat/Agent、只能自动选模型）** < Copilot Pro（$10/月，1500 AI credits，可自选模型）。

背景：2026 年 6 月 1 日起 Copilot 全系改为 AI Credits 按量计费，这就是缩水的来由。免费 Copilot Pro 现在只给认证教师和知名开源项目维护者。另外提醒：**Perplexity Pro 早年送过，现在已从 pack 页下线**，别再信老教程。

### 步骤 5：福利就绪后去免费领取页激活

审核通过、紫标亮起后，到学生门户 https://github.com/education/students 或福利页逐个领取；Copilot 可直接访问免费领取页 https://github.com/github-copilot/free_signup 按提示激活，无需绑卡。

⚠️ 实测发现：这个领取页现在会重定向到 Copilot Pro 的结账页（显示 $10/月）：

![free_signup 页面当前呈现：Pro 结账页（$10/月）](img/2026-10-17-AI会员免费薅/step4.png)

**如果只看到付费选项，说明你的学生福利还在处理中——千万不要付款**，再等几天，福利就绪后这里会显示免费领取。

## 注意事项、费用、坑点

- **费用：全免费**。申请、Copilot Student、包内权益全 $0。Student 正常对应 Pro 档（$10/月），免费拿到等于每月省 $10
- **认证有效期约 2 年**，到期需重新验证；GitHub 每月会复核资格
- **非学生硬蹭的高风险（必须看）**：
  - 用假学生证、PS 材料、买"代认证"服务（YouTube 上有卖 $2 代认证的，自称成功率 60%）→ 违反服务条款，轻则福利被撤销、重则账号被封
  - 社区有大量真实案例：福利被突然撤销、要求重新验证、重新提交秒拒、工单石沉大海
  - 就算混过初审，福利开通有延迟 + 每月复核，迟早掉
  - **结论：只适合真在读学生；已毕业 / 非学生不要尝试，别搭进去主力 GitHub 账号**
- **未验证提示**：国内高校学生证 / 学信网在读证明的具体通过率没有 2026 年专项实测数据，只能说官方接受、国内用户可用；Copilot Student 每月 AI Credits 具体数值官方没公布（第三方估算约 200 credits/月，非官方口径）；pack 页是动态的，动手前建议复核一次 https://education.github.com/pack
