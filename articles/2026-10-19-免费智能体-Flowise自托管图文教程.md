# 免费智能体（2）：Flowise 自托管——拖拽连线搭一个 AI 客服机器人

> 一句话导读：昨天写了 n8n（通用自动化），今天写 Flowise——它专为 LLM/Agent 应用而生：拖拽连线就能搭出带知识库的 AI 客服，开源免费，一条 Docker 命令跑在自己服务器上，数据不出门。

## 前置条件（需要什么）

- 一台能装 Docker 的机器：自己的电脑、或一台 VPS（2C4G 起步；免费 VPS 怎么领看 10-17 那篇《免费 VPS 横评》，甲骨文 A1 蹲容量依然是首选）
- 一个大模型 API Key：OpenAI、Mistral、或 Gemini（免费 tier 即可，见下）
- 一个域名（可选）：想把机器人挂到公网给客户用，配合 10-19 的 Cloudflare Tunnel 篇即可，不用买公网 IP

## 分步骤

### 步骤 1：看官方文档，确认安装方式

Flowise 官方文档的 Getting Started 页写得很清楚：支持 npm 全局安装和 Docker 两种方式，推荐 Docker。

![Flowise 官方文档 Getting Started 安装页](img/2026-10-19-免费智能体-Flowise/step1.png)

核心就两行（任选其一）：

```bash
# 方式一：npm（本机快速体验）
npm install -g flowise
npx flowise start

# 方式二：Docker（服务器部署推荐）
git clone https://github.com/FlowiseAI/Flowise.git
cd Flowise/docker
cp .env.example .env
docker compose up -d
```

跑起来后浏览器打开 `http://你的IP:3000`，第一次会让你设置管理员账号密码。

### 步骤 2：去 GitHub 仓库确认项目状态

Flowise 是 FlowiseAI 团队的开源项目（TypeScript），仓库里能看到 Docker 目录、`.env.example` 配置模板和最近的更新记录。自托管用户主要就看三样：star 数（社区活跃度）、docker 目录、文档链接。

![Flowise GitHub 仓库](img/2026-10-19-免费智能体-Flowise/step2.png)

生产环境注意 `.env` 里至少配这几项：`PORT`、`FLOWISE_USERNAME`、`FLOWISE_PASSWORD`，别用默认空密码裸奔。

### 步骤 3：去官网 Marketplace 白嫖模板，改成自己的客服机器人

自己从零连线当然可以，但最快的是去官网 Marketplace 找现成模板，比如 "Conversational Retrieval QA Chain"（对话式知识库问答）：

![Flowise 官网](img/2026-10-19-免费智能体-Flowise/step3.png)

动手流程（对照模板页）：

1. 进后台点 **Marketplace**，搜 "Customer Support" 或 "QA"，点 **Use Template**
2. 把模板里的 LLM 节点换成你有 key 的模型（比如把 Mistral 换成 ChatOpenAI，或 Gemini）
3. 上传你的产品文档（PDF/TXT）：文档加载器 → 文本切分（建议 1000 字符一块）→ 向量库
4. 向量库新手直接用 **In-Memory**（内存版，零配置）；量大了再换 Pinecone（有免费层）或自托管 Qdrant
5. 点右上角 **Save**，再点聊天图标实测，问几个产品问题看回答准不准
6. 满意后点 **Embed** 拿嵌入代码，贴到你的独立站/店铺页面，客服机器人就上线了

和 n8n 的区别一句话：n8n 是"什么自动化都能干"，Flowise 是"专门干 LLM 应用"，节点都是为大模型设计的（提示词、记忆、向量检索、Agent 循环），搭聊天机器人更快。

## 注意事项、费用、坑点

- **费用**：软件本身 0 元；花钱的地方只有服务器（免费 VPS 可覆盖）和模型 API 调用。Gemini 免费 tier、Mistral 免费层都够初期测试；OpenAI 按量很便宜，客服场景一天几毛钱。
- **长期免费风险**：自托管开源软件，不存在"被封号"，风险只在你自己服务器的稳定性。注意定期 `docker compose pull` 更新版本。
- **数据安全**：知识库文档都在你自己机器上，比用第三方 SaaS 版更适合放产品内部资料。
- **性能**：2C4G 跑 Flowise + In-Memory 向量库没问题；文档上万页再考虑独立向量数据库。
- **未验证**：官方 Cloud 版（flowiseai.com/cloud）的免费额度本文未核实，自托管用户可忽略。
