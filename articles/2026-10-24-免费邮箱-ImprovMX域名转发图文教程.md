# 免费域名邮箱转发实测：ImprovMX 让自有域名 5 分钟收信，直达 Gmail

**一句话导读**：手里有个域名但不想花钱买企业邮箱？ImprovMX 免费档帮你把 `info@你的域名.com` 这类地址的来信全部转发到 Gmail，1 个域名、25 个别名、每天 500 封，全程只改两条 DNS 记录。

## 前置条件（需要什么）

- **一个你自己的域名**（任何后缀都行，DNS 在哪家注册商都可以——这是它和 Cloudflare Email Routing 最大的区别，后者强制 DNS 托管在 Cloudflare）。
- **一个能收信的邮箱**（Gmail、Outlook、QQ 邮箱都行，用来接收转发的邮件）。
- **域名 DNS 面板的管理权限**（注册商后台，如 Namecheap、GoDaddy、Cloudflare、阿里云万网等）。
- 不需要：信用卡、不需要中国手机号、不需要备案。纯在线操作，约 5–10 分钟。

> 纠偏：网上有些老帖说 ImprovMX 免费档"无限域名"，那是过时信息。2026-10-24 核实官网价格页：**免费档 = 1 个域名**。想挂多个域名请看文末的替代方案。

## 分步骤

### 第 1 步：打开 ImprovMX，输入域名和目标邮箱

打开 [improvmx.com](https://improvmx.com/)。首页正中就是一个表单，两个框：**Your domain name**（填你的域名，如 `yourdomain.com`）和 **Your email address**（填用来收信的邮箱，如你的 Gmail）。

![ImprovMX 首页：输入域名和收信邮箱](img/2026-10-24-improvmx/step1.png)

填完点 **Create a free alias**（创建免费别名）。这一步不需要先注册账号，ImprovMX 会先给你生成 DNS 记录，引导你完成配置。

### 第 2 步：确认免费档额度，心里有数

在动手改 DNS 之前，先看一眼价格页，确认免费档够不够你用（2026-10-24 官网核实）：

![ImprovMX 价格页：Free 档 $0，1 个域名 / 25 个别名 / 每天 500 封转发](img/2026-10-24-improvmx/step2.png)

| 免费档包含 | 说明 |
|---|---|
| 1 个域名 | 只能绑一个域名 |
| 25 个别名 | 如 info@、support@、sales@…可建 25 个，默认还带 catch-all 通配 `*@域名`（所有没建别名的地址来信都收得到） |
| 每天 500 封转发 | 个人/小团队收询盘、注册验证邮件完全够用 |
| 7 天邮件日志 | 丢信了可查 7 天内的转发记录 |
| API 访问 | 可用 API 批量管理别名 |

**免费档没有 SMTP 发信**：只能收、不能用这个域名地址发信。想回信时显示 `info@你的域名`，需要付费档（$9/月起）或配合 Gmail 的"用其他地址发送"功能走 Gmail SMTP（见第 4 步）。

### 第 3 步：到域名商 DNS 面板添加 MX 和 TXT 记录

点完 Create a free alias 后，ImprovMX 会给你两组 DNS 记录。去你的域名注册商后台 → DNS 管理，按下面加（以 Namecheap / Cloudflare / 阿里云为例，字段名大同小异）：

| 类型 | 主机记录 | 记录值 | 优先级 |
|---|---|---|---|
| MX | @ | `mx1.improvmx.com` | 10 |
| MX | @ | `mx2.improvmx.com` | 20 |
| TXT | @ | `v=spf1 include:spf.improvmx.com ~all` | — |

三点注意：

1. **先删掉旧的 MX 记录**。如果域名之前配过别的邮箱服务（如腾讯企业邮、Zoho），残留的旧 MX 会让一部分信继续走老路，表现为"时而收得到时而收不到"，极难排查。
2. TXT 那条是 SPF 记录，作用是告诉全世界"只有 ImprovMX 的服务器能替这个域名收信"，防伪造、减少进垃圾箱概率。一个域名只能有一条 SPF 记录，如果已有别的 SPF（含 `v=spf1` 开头的 TXT），要把 `include:spf.improvmx.com` 合并进去，不要建两条。
3. 改完等 DNS 生效：通常 5–30 分钟，最长可能 48 小时（看 TTL 设置）。

### 第 4 步：回 ImprovMX 验证，添加别名并测试收信

回到 ImprovMX 页面点 **"I've added them, check now"**（我已添加，立即检查）。看到 **Email forwarding active**（转发已激活）就表示 DNS 生效了。

然后在控制台里：

1. **添加别名**：比如 `info@你的域名.com` → 转发到你的 Gmail；`support@` → 转发到另一个邮箱。一个别名可以转给多个目标邮箱。
2. **决定 catch-all 去留**：默认的 `*@你的域名.com` 通配会收下所有乱写的地址（如 `asdf@你的域名.com`）。好处是不漏信，坏处是垃圾邮件也会照单全收。建议保留，但把 Gmail 里给这类邮件加个过滤标签。
3. **发一封测试邮件**：用另一个邮箱给 `info@你的域名.com` 发信，看 Gmail 几秒到几分钟内能不能收到。

想实现"用域名地址回信"，可以在 Gmail 设置 → 账号和导入 → "用这个地址发送邮件" 里添加该地址，走 Gmail 的 SMTP 发出去（收件人看到的是你的域名地址，但邮件头会带 `via gmail.com` 或 `代发` 字样，介意的话就得上付费 SMTP）。这篇教程讲了 ImprovMX + Gmail 的完整联动：

## 注意事项、费用、坑点

**费用**：免费档 $0，无需绑卡。超了再考虑付费：Premium $9/月（30 个域名、100 别名/域名、每月 15 万封转发、12000 封 SMTP 发信）、Pro $24/月、Light $50/年（5 个域名）。个人收询盘、接网站表单通知，免费档长期够用。

**和本系列之前三篇的区别**（避免你配重复）：
- 10-16 的 Cloudflare Email Routing：免费且别名多达 200 个，**但强制 DNS 托管在 Cloudflare**。DNS 不在 CF、懒得迁移的，ImprovMX 更省事。
- 10-18 的 Zoho：是**完整邮箱**（有收件箱、可发信、5GB 存储），适合需要"真正邮箱"的人；ImprovMX 只是转发，没有收件箱。
- 10-21 的 Forward Email：免费档无限域名、无限转发量，更慷慨，但无网页控制台、纯配置文件/无界面管理；ImprovMX 有可视化面板和 API，对新手友好。

**坑点**：

1. **转发到 Gmail 偶发进垃圾箱**：有用户反馈经 ImprovMX 转发的信全进了 Gmail 垃圾箱（Reclaim Hosting 论坛 2025-08 实测帖）。ImprovMX 全档支持 SRS（发件人重写）来帮助 SPF 通过，但转发邮件的"身份"毕竟被改写过一次，Gmail 有时会更严格。缓解办法：把 SPF 配对、在 Gmail 里给转发地址建过滤器设为"永不发送到垃圾箱"、重要发件人加白名单。
2. **免费档每天 500 封是硬上限**：网站表单通知、用户注册验证这种量级没问题；拿来做 newsletter 群发会瞬间撞墙，那是付费场景。
3. **没有发件箱概念**：ImprovMX 服务器不存邮件，转发完就删（隐私角度是优点）。想留档就靠目标邮箱（Gmail）归档。
4. **域名是必须的**：和系列里所有域名邮箱方案一样，没有域名玩不转。还没有域名的先看本系列 10-22 的 pp.ua 免费域名篇。

**前科调查**：ImprovMX 从 2015 年左右运营至今，未发现停运、批量封号、免费档悄悄收费的前科，GDPR 合规。价格页"Forever free"表述稳定。风险等级：低。
