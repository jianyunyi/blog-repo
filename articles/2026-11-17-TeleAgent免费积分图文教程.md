## TeleAgent 是什么

TeleAgent（星辰超级智能体）是中国电信天翼 AI 推出的 AI 办公智能体，背后是电信自研的星辰大模型。它和普通聊天 AI 的区别是能真正"动手干活"：你用一句话交代任务，它会自己规划步骤、调用工具，最后交付成果——整理本地文件、写文档、做表格、查资料做调研、生成 PPT，甚至写代码搭一个小应用，都在它的活儿范围内。

目前有三种用法：

- **桌面版**：装在自己电脑上，任务在本地执行，文件要你逐个授权它才能碰。支持 Windows 10 及以上、macOS 13 及以上，另有 Linux 信创版（银河麒麟、统信 UOS）。
- **网页版**：11 月 2 日随 3.0 版本上线，不用安装，浏览器打开就能用，任务在一台云端 Windows 云电脑里跑（下面「网页版云电脑怎么用」一节细说）。
- **安卓 App**：已上线，可以远程遥控桌面端或连接云端版，出门在外发句话，家里的电脑就开干；iOS 和鸿蒙版官方说还在开发中。

在 IDC 发布的《中国企业级通用 Agent 产品技术评估》里，它综合得分排第三，并通过了信通院的智能体安全能力检验——央企出品，合规和安全这块是它的主打卖点。

## 领取步骤

**第 1 步：注册账号**
打开网页版 agent.teleai.com.cn，或在官网 teleai.com.cn 的产品页下载桌面版。用手机号 + 验证码注册并登录，不需要绑卡，也不用买任何套餐。

**第 2 步：领注册分和月度分**
首次登录后，3000 注册积分自动到账；当月的 3000 登录积分也会在首次登录时发放。首月 6000 分就齐了。到账情况在客户端点头像，或打开「积分福利社」查看积分明细和每笔的到期时间——**有到期时间的先用快到期的**，系统一般按到期先后抵扣，但自己心里有数更稳妥。

**第 3 步：每天签到**
打开客户端里的「积分福利社」，每日打卡领 100 积分。金额不大，但胜在天天有，攒一个月就是 3000，相当于多领一份月度分。

**第 4 步：（可选）邀请好友**
在福利社里生成你自己的邀请链接发给朋友。朋友通过链接注册、并在 7 天内登录，你得 500 积分（1 年有效），朋友得 3000 积分（1 个月有效），每月邀请奖励上限 30000 积分。注意别拿网上陌生人的邀请码注册——你得的还是那 3000 分，但对方白赚 500；要注册就直接走官网，或者用熟人的链接互相成全。

## 网页版云电脑怎么用

网页版是这次 3.0 更新的重头戏，也是限时免费里最值的一部分：

1. 打开网页版并登录，首次使用时平台会为你分配一台**专属 Windows 云电脑**，等右上角状态变成「运行中」就可以下任务了。
2. 任务都在这台云电脑里执行，不占你本机资源，也不需要你电脑开着。定时任务到点时，它还会自己把云电脑唤醒来执行。
3. 点「运行中」状态可以打开云电脑的桌面，像用一台普通 Windows 电脑一样装软件、整理文件。
4. 要交给它处理的文件，先上传到云电脑 **D 盘的 data 目录**——网页端「文件」里只认这个目录，其他位置的文件不会显示。
5. 长时间不用，云电脑会自动关机省资源，下次打开自动恢复，**工作空间、文件、定时任务和设置都会保留**，不用担心关机丢东西。

两个提醒：云电脑的具体配置（CPU、内存、硬盘）官方没有公布，别按高性能服务器期待；另外使用高峰期资源紧张，进去之后可能要排队等分配，急用的活儿尽量避开高峰。目前网页版限时免费的**结束时间官方没有公布**，想体验的趁早。

## 错峰半价：同样的积分，干两倍的活

官方有一条长期福利：**每天 22:00 到次日 08:00 使用 TeleAgent，所有任务的积分消耗直接打 5 折**。

用法很简单：把耗时的大活儿——批量处理文件、长篇调研、生成整套 PPT、多轮调试代码——攒到晚上 10 点之后再跑；白天只处理急事和小事。配合桌面版/云电脑的定时任务，你甚至可以睡前把任务排好，让它在半价时段自己跑完，早上起来收成果。

## 积分怎么花：先看消耗，再选档位

积分是 TeleAgent 的统一计量单位，1 次任务的消耗取决于任务复杂度和调用的模型，官方明确说**不设固定的 Token 兑换比例**。官方资费文档给了实测参考（日间价）：

| 任务场景 | 单次消耗参考 | 常见水平 |
| --- | --- | --- |
| 深度调研 | 30–120 积分 | 约 70 |
| 表格分析与处理 | 37–110 积分 | 约 45 |
| 搭应用、写代码 | 20–100 积分 | 约 35 |
| 文档撰写与处理 | 20–200 积分 | 约 60 |
| 任务执行（整理文件等） | 20–90 积分 | 约 40 |

照这个消耗算，首月 6000 积分大约够跑 80–100 个常规任务，轻度办公绰绰有余；再叠加错峰半价，耐用度还能翻倍。

模型有**智能、极速、旗舰三档**可选：极速档响应快、适合简单任务；旗舰档能力最强，留给复杂活儿；拿不准就用智能档。具体每档对应哪个模型、各档的积分倍率，**官方没有公布**，建议的用法是：日常任务先用智能或极速跑，效果不满意再换旗舰重跑，别一上来就全程旗舰烧积分。另外它也支持接入自定义模型（填自己的 API Key），有现成额度的可以走自己的 Key，把免费积分省下来。

## 付费套餐：一句话版本

真用超了再考虑付费：个人套餐三档，月付 49 / 99 / 199 元（基础版 / 标准版 / 高级版），连续包月有折扣；也有按量买的积分加油包。免费积分够用之前，没必要花这个钱。

## 注意事项

1. **积分只能在 TeleAgent 里用，不能导出成 API Key**，也不能提现、转让。别把它和中国电信的另一个产品「星辰 TokenHub」搞混——TokenHub 是面向开发者的模型 API 平台，卖的是 API Token；TeleAgent 是给你直接干活的智能体产品，两边账号权益不互通。
2. **每笔积分都有有效期**，过期作废、不结转。尤其是每月登录送的 3000 当月清零，签到分也要看明细里的到期时间，别囤着。
3. **活动规则以官方当期公示为准**。这套福利从今年 8 月积分体系上线以来已经调整过几轮（比如邀请活动原定 9 月底结束），本文的口径核对至 2026 年 11 月中旬，领取前请以客户端「积分福利社」和官网的实时展示为准。
4. **桌面版会申请文件授权**。它处理本地文件前需要你授权文件夹，敏感资料建议单独放、谨慎授权，授权时养成选"允许一次"的习惯，重要文件先备份。
5. **交付成果记得自己验收**。再强的智能体也会出错，文档、表格、数据类的产出交出去之前，自己快速过一遍。
6. 注册认准官网 **teleai.com.cn** 和网页版 **agent.teleai.com.cn**，不要从来路不明的链接下载客户端，更不要用别人的邀请链接注册陌生账号。
