# 免费云托管：Render 免费档图文教程——0 元把网站跑起来，但先看清 15 分钟休眠和 30 天数据库

**一句话导读：** 有个小项目想上线给人看、又不想先掏服务器钱的时候，Render 的免费档是目前最省事的路线之一：连 GitHub 仓库、点几下就能部署，静态站一直免费、动态网站也不收月费；但免费档有三条硬线——网站闲置 15 分钟就休眠、免费数据库 30 天到期、每个工作区每月只有 750 小时免费实例时间，拿它跑正式生产一定会踩坑，拿它做演示、练手、小工具正合适。

## 前置条件（需要什么）

- 一个 GitHub 账号 + 一个能跑起来的项目仓库（Node.js、Python、Go、Ruby、Rust、Elixir、PHP 或 Docker 都行；纯静态站也行）
- 项目里有明确的启动命令（比如 `npm start`、Python 的 `gunicorn` 启动命令），Render 部署时要填
- 心理预期：免费档不是“无限免费服务器”，演示流量够用、正式用户一多就得升级到 $7/月的付费实例

## 分步骤

### 第 1 步：先看 Render 官网，确认免费档到底包含什么

![Render 官网首页](img/2026-10-31-render/step1.png)

打开 Render 官网，先看它的服务形态：它是一个托管平台，代码推到 GitHub 就能自动部署，不用自己装系统、配 Nginx。免费档覆盖四类：Web Service（动态网站）、Postgres 数据库、Key Value（Redis 兼容的键值存储）、静态站。注意：后台任务、私有服务、定时任务从一开始就没有免费档，必须上付费实例——你的项目如果依赖后台常驻任务，别指望免费档兜底。

### 第 2 步：读定价页，算清免费档的四条硬线

![Render 定价页：Hobby 工作区 $0 + 按服务计费](img/2026-10-31-render/step2.png)

定价页的关键句要先读懂：工作区 Hobby 档是 $0/月，但“$0 + compute”——工作区费用和算力费用是分开算的，免费实例本身不收费，但它的限制不会因为你升级工作区而解除。具体四条线（2026 年 10 月官方文档口径）：

1. **15 分钟休眠：** 免费 Web Service 连续 15 分钟没有入站请求（HTTP 或 WebSocket）就会关机，下一次访问要等约 1 分钟重新启动，访客会先看到 Render 的加载页。
2. **750 小时/月：** 每个工作区每月共享 750 小时免费实例时间；跑满后当月所有免费 Web Service 都会被暂停，直到下月重置——一个全月不间断跑的服务正好约 720 小时，所以单服务勉强够，两个服务同时全月跑一定超。
3. **免费 Postgres 30 天到期：** 免费数据库自创建起 30 天后过期，另有 14 天宽限期可升级，过期不升级数据会被删除；且每个工作区只能有一个免费 Postgres，存储上限 1GB。
4. **规格与功能上限：** 免费实例 512MB 内存、共享 CPU，只能跑 1 个实例，不能挂持久磁盘、不能开 shell、不能跑一次性任务，25/465/587 端口不出站邮件。

### 第 3 步：读免费档官方文档，确认部署方式和静态站的区别

![Render 免费档官方文档](img/2026-10-31-render/step3.png)

官方免费档文档把部署路径讲清楚了：新建 Web Service → 连 GitHub 仓库 → 选运行环境 → 填构建命令和启动命令 → 选 Free 实例类型 → 部署。静态站走另一条线：Render 的静态站“一直免费部署”，没有休眠问题（因为它只是文件托管、不跑服务进程），但 Hobby 工作区的带宽是 5GB/月 pooled（所有服务共用），超了按 $0.15/GB 计费——静态站 + 动态服务混在一个工作区里，带宽是同一池子。

实操建议：先把前端静态站和后端 API 分开看——能静态化的页面先走静态站，别让所有流量都去唤醒那个会休眠的免费 Web Service；数据库如果只是演示，用完 30 天就当它会消失，重要数据定期导出备份，别把它当长期库。

### 第 4 步：按第三方实测清单验收——休眠、唤醒、robots.txt 三件事

![Render 免费档实测：休眠、数据库期限与 robots.txt](img/2026-10-31-render/step4.png)

按 2026 年 9–10 月的多篇实测核对，部署完要亲手验三件事再对外发链接：

1. **休眠唤醒：** 部署完先访问一次确认能打开；然后放 15 分钟以上别碰它，再访问一次，计时从点开到首屏出现是不是约 1 分钟——如果是，说明休眠机制如文档所说，分享链接时要跟对方打好招呼“第一次打开要等一会儿”。
2. **数据库倒计时：** 记下免费 Postgres 的创建日期，第 30 天就是到期日；演示项目在到期前要么升级到 $6/月起的付费库，要么把数据导出、换地方存。
3. **robots.txt 陷阱：** 免费服务休眠期间，Render 对 `/robots.txt` 请求会自动返回全部禁止抓取——也就是说搜索引擎可能在服务睡觉时来爬、爬到禁令。指望搜索引擎收录的正式站，别用免费档；演示站无所谓。

验收通过后，升级路径也先想好：真正要 24 小时在线、不休眠，升级的是“服务实例”本身（Web Service 从 Free 换成 $7/月起的付费实例），而不是把 Hobby 工作区升级成 Pro——官方文档原话：升级工作区并不能解除免费实例的限制。

## 注意事项、费用、坑点

- **费用：** Hobby 工作区 $0/月；免费 Web Service $0、免费静态站 $0、免费 Postgres $0（30 天）；付费 Web Service $7/月起、付费 Postgres $6/月起；Hobby 带宽 5GB/月后 $0.15/GB。所有数字以部署时 Render 定价页为准，第三方实测的旧数字（如 100GB 带宽、$19/人 Pro）已过时，别照抄。
- **前科核查：** Render 免费档的限制是明文写在文档里的，不是“悄悄收费”——休眠、30 天库、750 小时都是官方规则；没有批量封号、突然下线免费档的公开前科。但它明确写了“免费实例不要用于生产应用”，拿它跑收款、跑客户正式服务，风险是你自己的选择，不是平台违约。
- **别踩的坑：** ① 以为升级工作区就能不休眠——必须升级服务实例才行；② 两个免费服务全月同时跑，750 小时池子月中就空了；③ 把唯一一份数据放在免费 Postgres 里，30 天到期 14 天后删除；④ 后台任务、定时任务一开始就上免费档——它们根本没有免费类型；⑤ 拿免费档链接去做 SEO、等搜索引擎收录，休眠期的 robots.txt 会挡路。
