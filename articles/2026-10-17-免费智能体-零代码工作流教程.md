# 不想把客户资料交给平台？Dify 开源版自托管：智能体自己搭、数据自己管

> 一句话导读：10-14 那篇讲的是扣子 Coze——字节的 SaaS，开箱即用，但数据和账单都在平台手里。这篇讲另一条路：Dify 社区版，开源免费、自己服务器上跑，聊天助手、知识库问答、Agent 全功能不阉割，代价是一台 2C4G 的小服务器和半小时折腾。

## 先说结论：免费版到底能干什么

Dify 是个开源的 LLM 应用开发平台（GitHub 15.5 万 star，2026 年 9 月还在活跃更新），定位就是"可视化造智能体"：拖拖拽拽就能做出聊天机器人、RAG 知识库问答、Agent 和工作流，还能一键发布成 API 给你的网站/店铺调用。

免费有两条路：

| | Dify 社区版（自托管） | Dify 云 Sandbox 档 |
|---|---|---|
| 价格 | 软件 $0，自己出服务器钱 | $0 |
| 功能 | 全功能，不阉割 | 受限：5 个应用、1 个用户、50 个知识库文档、50MB 存储 |
| 用量 | 无限，自己接模型 API key 或本地模型 | 200 message credits（额度极小，只够尝鲜；是总额还是按月，不同来源说法不一，以官网为准） |
| 数据 | 在你自己服务器上 | 在 Dify 云上 |

**给跨境创业者的一句话**：客户资料、产品文档、询盘记录这种东西，放在 Coze 这类 SaaS 上等于寄人篱下；Dify 自托管跑在你自己的 VPS 上，数据不出你的机器。这是它和 Coze 那篇最大的区别——Coze 赢在零门槛，Dify 赢在"我的地盘我做主"，且没有按量计费的表在转。

## 前置条件

1. **一台 VPS**：2 核 CPU、4GB 内存、40GB 以上 SSD，Ubuntu 22.04/24.04。这是 Dify 官方文档的最低线（RAG 文档量大的话建议 8GB 内存）。约 $5/月；甲骨文免费 A1（4 核 24GB）理论上绰绰有余，但官方镜像对 ARM 的支持情况**未验证**，动手前先确认。
2. **Docker + Docker Compose**：Docker 19.03+、Compose 1.28+（新版 Docker 自带 `docker compose`）。
3. **模型**：二选一——① 你自己的 API key（OpenAI、Claude、DeepSeek 等，Dify 支持几十家供应商）；② 本地 Ollama 模型，零 API 成本（见步骤四）。
4. 会用 SSH 连服务器、会复制粘贴命令。不需要会写代码。

## 步骤一：服务器上装好 Docker

SSH 连上 VPS，先把 Docker 装好（Ubuntu）：

```
sudo apt update && sudo apt upgrade -y
sudo apt install -y docker.io docker-compose
sudo systemctl status docker
```

看到 active (running) 就行。已经装过的跳过。

## 步骤二：一条命令拉起 Dify

Dify 官方推荐 Docker Compose 部署，整个平台是十来个容器（前端、API、worker、Postgres、Redis、向量数据库 Weaviate 等，一次全起来）：

```
git clone https://github.com/langgenius/dify.git
cd dify/docker
cp .env.example .env
docker compose up -d
```

第一次跑要拉镜像，等 5–10 分钟。跑完 `docker compose ps` 确认所有容器都是 running 状态。

## 步骤三：打开网页，建管理员账号

浏览器打开 `http://你的服务器IP`（默认 80 端口），第一次会进 `/install` 页面：填邮箱、用户名、密码，建管理员账号，重新登录就进控制台了。

到这一步，你已经有了一个和 Dify 云端长得一样的智能体平台，跑在你自己的机器上。

## 步骤四：接模型（两种接法，按钱包选）

进右上角头像 → 设置 → 模型供应商。

**接法 A：填 API key（最省心）**。选你的供应商（比如 DeepSeek、OpenAI），填 key，保存。之后所有应用的调用都走这个 key，费用就是模型官方的按量价，Dify 平台本身不抽成。

**接法 B：Ollama 本地模型（零模型成本）**。服务器上（或另一台机器）装 Ollama 拉个模型，然后在 Dify 里选 Ollama 供应商，填：

- 模型名称：比如 `qwen3:14b`（你拉的什么写什么）
- Base URL：`http://<Ollama所在机器的IP>:11434`（注意：Dify 跑在 Docker 里，`localhost` 指的是容器自己，所以要填宿主机的局域网 IP 或公网 IP，不能填 localhost）
- 模型类型：对话；上下文长度按模型填（不清楚就 4096）

点保存，校验通过就能用。实测教程里这是通的（腾讯云开发者社区、DEV 都有 2026 年的实测帖）。

## 步骤五：建第一个智能体，发布上线

1. 控制台点"创建应用"，选 **Chatbot**（对话客服）或 **Agent**（能调用工具、更自主）。
2. 选刚才接好的模型，写 system prompt（比如"我们是做 XX 品类的跨境店铺，回答客户询盘"）。
3. （可选）"知识库"里上传产品手册、FAQ 文档——这就是 RAG，机器人会基于你的文档回答，而不是瞎编。
4. 点发布：Dify 会给你一个可公开访问的 Web App 链接，还能一键生成 API，嵌到你的独立站或客服系统里。

和 Coze 那篇的客服机器人比，流程几乎一样，区别只在"跑在哪、数据归谁"。

## 免费额度、限制与坑点

**社区版真正的限制只有两个**：

1. **许可证有个"modified"**：Dify 是修改版 Apache 2.0，不是纯开源。个人/单个 workspace 自用完全免费；但如果你要给第二个客户开独立 workspace（多租户），就要买商业许可（Enterprise，询价）。自己一个店自己用，不受影响。
2. **服务器和模型钱自己出**：平台免费，但 VPS（~$5/月）和模型 API 调用费是实打实的。用 Ollama 本地模型的话，模型费也能省掉——代价是吃你服务器的 CPU/内存，小模型还行，大模型得加显卡。

**云 Sandbox 档别当生产用**：200 credits 烧完就没了，知识库 50 个文档、50MB 上限，做个 demo 够，上线不够。

**前车之鉴**：同类开源项目 Flowise 在 2026 年 8 月 31 日宣布停止维护（EOL）。Dify 目前更新活跃、star 数是同类最高，但"长期免费"这件事永远要看项目健康度——自托管的好处恰恰是：就算官方哪天变卦，你手里这套代码和数据还在自己服务器上跑，不会被一键关停。

**和 n8n 的区别**（顺手提一句，免得你搜到它纠结）：n8n 也是自托管免费（社区版无执行次数限制），但它是**自动化工作流**工具（定时任务、API 串联），AI 只是其中一种节点；Dify 是**为 LLM 应用生的**（聊天、RAG、Agent）。你要的是智能体，Dify 更对口。n8n 云版 2026 年已没有永久免费档（只有 14 天试用），别指望白嫖云端。

## 给跨境创业者的建议

- 先拿 Dify 云 Sandbox 档花半小时摸一遍界面，确认是你要的东西；
- 真要上生产，走社区版自托管：一台 2C4G VPS + Docker，半小时搭好，数据、用量全自己说了算；
- 客服场景直接复用 10-14 那篇 Coze 教程的 prompt 和知识库思路，搬过来就能用。
