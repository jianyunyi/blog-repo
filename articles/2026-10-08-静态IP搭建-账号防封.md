## 一、平台风控到底在看 IP 的什么

平台判断“你是不是真人”，IP 是第一道关。常见的判死刑行为：

- **IP 频繁跳变**：上一秒美国，下一秒新加坡——真人不可能这样上网
- **机房 IP 段**：IP 一看就是数据中心（hosting），而不是家庭宽带
- **黑历史**：这个 IP 之前被用来群发垃圾、批量注册过，已经进了黑名单
- **环境不一致**：IP 显示美国，浏览器时区却是东八区，系统语言是中文——直接露馅

## 二、三个概念先搞懂

**动态 vs 静态**：动态 IP 每次连接都变，静态 IP 长期固定。养账号一定要静态——天天换 IP 等于天天告诉平台“我很可疑”。

**机房 IP vs 住宅 IP**：VPS、云服务器的 IP 属于机房（在 ipinfo 这类工具上显示为 hosting）；家庭宽带的 IP 显示为 isp。平台对住宅 IP 的信任度天然更高。

**独享 vs 共享**：共享 IP 池里可能前一个人刚用它发过垃圾邮件，黑锅你来背。核心账号务必独享。

## 三、三条路线，怎么选

### 路线一：VPS 自建（便宜，适合跑业务）

买一台海外 VPS（比如 Oracle 免费套餐、新加坡/美西节点，Vultr、DigitalOcean 约 5 美元/月起），你就拥有了一个固定的公网 IP，完全独享、长期不变。优点是便宜甚至免费，缺点是 IP 属于机房段。**适合：跑网站、API、脚本、服务器任务；不适合：注册和养护高风控的社媒/电商账号。**开机步骤见第四部分。

### 路线二：静态住宅 IP 服务（养号专用）

市面上有专门做静态住宅 IP 的服务商（按教程中的参考价，约 3–5 美元/月），提供独享的原生家庭宽带 IP，多为双 ISP 属性，无限流量。配合指纹浏览器（AdsPower 这类）使用，是跨境电商、社媒账号运营的主流方案。注意：这是第三方商用服务，**下单前请自行核实商家口碑，价格与质量以实际为准**——我们未逐一实测这些服务。

### 路线三：免费 VPN / 免费代理（千万别碰）

免费代理的 IP 池早被无数人玩烂了：黑名单、滥用记录一个不少。用它登录账号，不是省钱，是花钱买封号。核心账号远离一切免费代理。

### 4.1 Oracle Cloud 免费套餐

官方免费档（Free Tier）：30 天 300 美元试用额度 + 长期免费的 Always Free 资源（Ampere A1 等计算资源在账号生命周期内免费，须建在 home region）。官方要求一人一户，禁止注册多个免费账号。

### 4.2 Vultr

1. **注册**：到 vultr.com 注册账户——邮箱 + 密码（官方要求至少 10 位、含大小写字母与数字），点邮件里的链接验证，再填写账单信息并绑定付款方式（支持信用卡等，以官网为准）；

## 五、4 项体检工具：打开什么、输入什么、看什么、合格线

不管 IP 从哪来，上线前先体检，至少用 2–3 个工具交叉验证（单一工具说“干净”不等于真干净）：

### 1. Scamalytics（scamalytics.com/ip）

1. 打开网址，在输入框填入待查 IP；
2. 看 **Fraud Score（0–100）**：官网分档为 0–19 低风险、20–59 中、60–89 高、90–100 极高——分数含义约等于“该 IP 段被关联欺诈的比例”；
3. **合格线：0–20 分（低风险档）为优**；超过 60 分的 IP 别碰账号。

### 2. IPinfo（ipinfo.io）

1. 打开网址，输入 IP；
2. 看 **ASN / 公司类型**：显示 isp 是住宅宽带，显示 hosting 是机房；顺便核对国家 / 城市定位是否与目标一致；
3. **合格线**：养号场景要 isp（住宅）；跑业务用 hosting 也无妨，但别骗自己是住宅。

### 3. Whoer（whoer.net）

1. **在代理环境下打开** whoer.net（它检测的是你当前连接）；
2. 重点看三项是否提示“different”：**System time different**（系统时间与 IP 所在时区不一致）、**Languages different**（系统/浏览器语言与 IP 国家不一致）、**DNS different**（DNS 服务器国家与 IP 国家不一致）；同时看 ISP 与 Hostname 是否暴露代理/机房特征；
3. **合格线**：时区、语言、DNS 全部与 IP 所在国一致，无任何“different”提示。

### 4. AbuseIPDB（abuseipdb.com）

1. 打开网址，输入 IP 查询；
2. 看 **滥用举报记录**（垃圾邮件、攻击、群发等）及最近举报时间；
3. **合格线**：无近期滥用记录；举报密集或刚被举报过的 IP 直接淘汰。

体检口诀：**分数要低、类型要对、环境要一致、历史要干净。**任何一项爆红，这个 IP 就不配碰你的核心账号。

## 六、手把手：指纹浏览器绑定代理（步骤概述）

以 AdsPower 这类指纹浏览器为例（各产品界面不同，**按所用产品当前页面指引操作，精确路径待核实**）：

1. **新建浏览器配置**：在指纹浏览器里新建一个独立配置（一个账号一个配置，互不串环境）；
2. **代理设置**：在配置的代理选项里选协议（HTTP / SOCKS5 等），填入代理主机、端口、账号密码（如有）；
3. **测试连接**：用产品自带的检测按钮测代理连通性，通过后保存；
4. **开浏览器验证**：用该配置打开浏览器，访问 whoer.net 确认 IP、时区、语言、DNS 一致。

## 七、链式代理配置思路（前置节点 + 落地 IP）

进阶玩法叫“链式代理”，结构是：**本地 → 前置节点（VPS，负责连通）→ 落地 IP（静态住宅，负责“身份”）→ 目标站点**。

1. **前置节点**：用第四部分开的 VPS 做入口，解决“连得出去”的问题——流量先出境；
2. **落地 IP**：出口用静态住宅 IP，把流量“装成本地人”——平台看到的是住宅段、位置一致；
3. **两层都体检**：前置节点和落地 IP 分别过第五部分的 4 项体检；
4. **稳定压倒一切**：链上任何一环频繁变动都会放大风控风险，配好后不要随便换。

## 八、避坑清单

- 不要频繁切换节点/地区，稳定压倒一切
- 一个 IP 不要登录一堆账号，关联封号连坐
- IP 和浏览器环境要配套：美国 IP 就配英文+美西时区，用指纹浏览器隔离每个账号的环境
- 进阶玩法叫“链式代理”：前置节点负责连通，落地用静态住宅 IP——流量先出境再“装成本地人”

## 常见问题

### 账号总被封和 IP 有什么关系？

平台风控首先看 IP：是否频繁跳变、是否为机房 IP 段、IP 是否有黑历史、IP 与浏览器时区语言是否一致，任何一项异常都可能触发风控。

### VPS 的 IP 能用来养号吗？

VPS 的是机房 IP，适合跑网站、API 和脚本；注册和养护高风控的社媒/电商账号，建议用静态住宅 IP。

### 免费 VPN / 免费代理能用吗？

不能。免费代理的 IP 池早被无数人用烂，黑名单和滥用记录多，用它登录核心账号等于花钱买封号。

### 怎么检查一个 IP 干不干净？

四项体检：Scamalytics 看欺诈分数（0–20 分为优）、IPinfo 看是 isp 还是 hosting、Whoer 看时区语言 DNS 是否一致、AbuseIPDB 看有无滥用举报记录。
