## 一、免费额度（按模型分别算，2026-10 核实）

🔹 **gpt-oss-120b / 20b**（OpenAI 开源模型）：每分钟 30 次、每天 1000 次、每天 20 万 token；

## 二、注册与接入：三分钟

1）打开 **console.groq.com**，用邮箱或 Google / GitHub 注册，不要卡；2）在 API Keys 页一键生成 Key；3）接口是 **OpenAI 兼容**的：把你原来 OpenAI SDK 的 base\_url 换成 https://api.groq.com/openai/v1、填上 Groq 的 Key 就能跑，现成项目改一行。速度参考：gpt-oss-20b 约 1000 token/秒量级，70B 级模型也有 300 上下——做实时对话和 Agent 工具调用时，这个延迟优势是肉身体验级别的。

## 三、按场景选模型

日常对话/Agent 主力：gpt-oss-120b（质量与额度最均衡）；量大管饱的杂活（分类、打标、简单改写）：Llama 3.1 8B 或 gpt-oss-20b；中文与看图：Qwen 预览版（注意预览版可能随时下架）；播客/会议/视频转字幕：Whisper Large V3，每天 8 小时对个人项目基本等于无限。一个实用的排班：白天交互用大模型，批量任务丢给 8B，音频全走 Whisper，三份额度各花各的、互不挤占。

## 四、坑与注意事项

1）只有开源模型，没有 GPT/Claude/Gemini 本尊，冲着某个闭源模型来的绕道；2）Groq 今年已下架过多个模型，正式项目前面挂一层网关（如 LiteLLM / OpenRouter），模型下线时改配置而不是改代码；3）免费档定位是开发测试，别把生产业务的命脉押在免费额度上；4）超限返回 429，老实按响应头做退避重试，别硬刷。
