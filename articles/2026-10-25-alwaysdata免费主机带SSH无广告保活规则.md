# alwaysdata 免费主机：带 SSH、无广告，保活规则一次讲清
今天介绍一个法国老牌主机商 alwaysdata 的免费档。它最大的卖点就两个：**免费档自带 SSH**，而且**全程无广告**。但有一个卡点必须先说在前面，不然你注册到一半会愣住。
## 先说卡点：注册要验证信用卡
官网首页写着“无需信用卡注册”，但实际打开注册页，页面明确要求**先验证一张信用卡或借记卡（防滥用）**，同时写着不会扣任何费用。两处口径不一致，以注册页实际要求为准。
如果不验证，官方文档说账户会进入**受限模式**：HTTP 处理更慢、过滤更严、发信数量和时间受限。解除办法就是补一张卡信息，或者在平台付过一次款。能不能接受这一步，你先想好再动手。
## 免费档到底给什么
套餐页写的是 0 欧元、终身有效、个人用途、无广告，配置如下：
- **磁盘：**1GB SSD
- **内存：**256MB，CPU：1/4 核
- **备份：**保留 3 天
- **站点、域名、数据库、邮箱：**不限数量
- **SSL 证书：**免费
- **SSH：**包含在内（见下文）
- **语言：**PHP、Python、Node.js、Ruby、Java 等多语言都支持
1GB 磁盘放小站、脚本、个人项目够用，放不了大文件和媒体库，这个预期要先摆正。
## 保活规则：按账号年龄算，比 Serv00 宽松
免费档不是无条件永久，官方文档的“缺乏活动”条款写得很清楚：长时间不登录管理界面，账户会被停用。具体周期按建号时间算：
- **建号不满 1 年：**每 120 天登录一次管理界面
- **建号 1–4 年：**每 6 个月登录一次
- **建号满 4 年：**每年登录一次
只要按时登录一次就能续上，不用跑什么脚本。对比之前介绍过的 Serv00（90 天登录一次），alwaysdata 的保活压力更小。
## 注册步骤（已核实到表单这一步）
以下步骤核实自官网注册页首屏，提交之后的部分本次没有实测，以页面实际提示为准：
**第一步：**打开 alwaysdata 官网，进入免费套餐（Free offer）页面，点注册入口。
**第二步：**注册表单只填三样东西——邮箱地址（必填，说明是用于登录管理界面）、密码（必填）、勾选个人数据保护政策。没有用户名、没有手机号字段，首屏也没看到验证码和名额排队提示。
**第三步：**点“Create my profile”之前，页面会要求验证信用卡或借记卡（见开头卡点）。提交后是否要邮箱验证、后续会不会出现验证码，本次只读核查没有走到这一步，**没有实测结论**，按页面提示走就行。
## SSH 怎么连
官方文档的说法和很多二手资料不一样：SSH 不是在面板里手动开开关，而是**随账户默认创建了一个和账号同名的 SSH 用户**。
- **管理位置：**管理界面 → Remote access → SSH，可以管理 SSH 用户、查看服务器指纹、设置 shell
- **连接地址：**ssh-[你的账号].alwaysdata.net，端口 22
- **登录方式：**首次连接用该用户的密码，之后可以改用 SSH 密钥连接
- **网页版 SSH：**也可以用浏览器打开 ssh-[你的账号].alwaysdata.net，但官方文档自己都说不稳定、比较慢，不能替代 SSH 客户端
注意这是托管环境，**没有 root 权限**，SSH 用户可以在账户目录内自由移动，但改不了系统层面的东西。
## 限制与避坑
- **没有 Docker、Redis、Memcached、ElasticSearch、防火墙管理、VPN**，这些是付费私有云才有的，免费档是 Public Cloud，给不了。
- **不验证卡 = 受限模式**，速度和发信都会打折，见开头。
- **1GB 磁盘、256MB 内存**，跑重应用、常驻大程序就别想了，适合静态站、轻量接口、小脚本。
- **保活靠登录管理界面**，不是靠访问网站，定个日历提醒最稳。
- **个人用途**，套餐页写明是 for personal needs，商用项目不合适。
## 和 Serv00 怎么选
一句话：**不想绑卡选 Serv00（邮箱注册、90 天登录保号）；能接受验证卡、想要更宽松保活和无广告体验，选 alwaysdata。**两个都是真免费、真带 SSH，区别主要在绑卡和保活周期上。
