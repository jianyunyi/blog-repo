# 免费二级域名：afraid.org 25 年老站，5 分钟拿一个能用的子域名（图文教程）

> 一句话导读：Freenom 死后，免费域名只剩 Northwest 的首个 .com 能薅一次。今天补一条长期的路：afraid.org（FreeDNS）运营 25 年，免费拿 `你的名字.mooo.com` 这样的子域名，即刻生效、无隐藏收费。适合测试站、跳转页、内网服务；要做品牌门面，还是攒钱买正经域名。

## 前置条件

- 一个邮箱（注册用，激活邮件来自 dnsadmin@afraid.org，注意查垃圾箱）
- 同意它的 AUP/TOS；中国不在美制裁名单地区，不受影响
- 预期管理：这是**共享子域名**（寄人篱下），Google 默认不收录，不适合当品牌官网

## 步骤 1：打开官网，确认它还活着

https://freedns.afraid.org/（2026-10-16 实测）：

![步骤1：freedns.afraid.org 首页，FreeDNS 免费 DNS / 动态 DNS / 子域名托管](img/2026-10-16-免费二级域名/step1.png)

首页实时数据：700 多万会员、2 万多个共享域名、1300 多万条解析记录——注册库是活跃的（2026-10-13 还有第三方抓取器在更新它的可用共享域名列表）。从 2001 年运营到现在，免费层无批量封号、无悄悄收费的前科。

## 步骤 2：注册账号（只看不填的截图，照着填就行）

点左侧 Signup，或直接打开 https://freedns.afraid.org/signup/ ：

![步骤2：afraid.org 注册页：用户名、邮箱、密码、验证码](img/2026-10-16-免费二级域名/step2.png)

填名、姓、UserID、密码、邮箱和验证码，提交后去邮箱点激活链接（瞬时发送）。**Premium 会员是捐赠制可选项**（解锁隐藏域名等高级功能），免费功能不被限制——看到付费入口别慌，不掏钱也能用全套免费功能。

## 步骤 3：5 分钟拿下你的第一个免费子域名

登录后点左侧 **Subdomains → 右上角 Add**，在域名列表里选一个。选域名是关键决策，看 FAQ 页的官方提示（2026-10-16 实测）：

![步骤3：afraid.org FAQ：免费额度与共享域名风险提示](img/2026-10-16-免费二级域名/step3.png)

- **免费额度**：免费账户最多 5 个子域名；DNS TTL 1 小时；还带 Dynamic DNS 和免费 URL 跳转。
- **选哪个共享域名**：优先选官网 FAQ 点名"官方自持"的 **mooo.com、strangled.net** 这类——长寿概率最高。也可在 Preferences 里让系统默认只显示官方域名。
- **最大风险**：共享域名是别人捐的，**域名所有者随时可能撤掉**。官网 FAQ 原话警告：它可能存活很多年，也可能下周就消失。所以：测试、跳转、临时项目随便玩；长期生意别把唯一入口押在这上面。

填上你想要的前缀（比如 `myshop`），点 Add，**即刻生效**——`myshop.mooo.com` 就归你了。然后去 Subdomains 列表里点它，填 A 记录指向你的服务器 IP（或做 URL 跳转），1 小时内全球生效。

## 备选方案

**DuckDNS（duckdns.org）——动态 IP 专用。** 还活着、真免费，最多可注册多个 `*.duckdns.org` 子域名（历史为 5 个），无 30 天强制续签（对比 No-IP 的 30 天确认是它最大优点）。注册：用 GitHub / Google / 邮箱登录 → 填前缀点 "add domain" → 记下 token，动态更新调接口 `https://www.duckdns.org/update?domains=你的前缀&token=你的token&ip=`。**坑**：2026-06 实测它的 nameserver 间歇性对 Let's Encrypt 校验返回 SERVFAIL，HTTPS 证书签发会卡死；解析偶发超时。结论：**当"动态 IP 找服务器"用可以，当店面域名不行**。

**eu.org（nic.eu.org）——抽奖级。** 首页仍宣传免费注册、通道存在，但**审批严重积压**：2026-05 有用户三级域名获批，另一用户 2023 年提交至今没批、还有等了 18 个月的。政策倾向非商业/个人用途，还要自备 nameserver（可托管到 Cloudflare）。写法：**可申请、别指望**——提交一个碰运气，同时用 afraid.org 先跑起来。

**在校生专区：GitHub Student Pack → 免费 .me 一年。** education.github.com/pack（2026-10-16 核实页面实时）：Namecheap 福利 = **.me 域名首年免费 + 1 年免费 SSL**；Name.com 还有 .dev/.app 等后缀任选其一。兑换：学生验证通过 → nc.me 用 GitHub 授权登录 → 搜 .me 加购 → $0 结账**无需绑卡**。硬门槛：在读学生 + 学校邮箱/在读证明；**续费 .me 约 $23.98/年**，第二年起要花钱——不是永久免费。

**反面教材：DigitalPlat（us.kg 等）。** 90 天点一次续签的免费域名，nameserver 长期不稳定，InfinityFree 官方明确不推荐。看到就绕道。

## 费用与坑点总结

| 方案 | 费用 | 适合 | 定位 |
|---|---|---|---|
| afraid.org | $0，5 个子域名 | 测试站、跳转、内网服务 | 主推 |
| DuckDNS | $0 | 动态 IP 找服务器 | 备选（场景限定） |
| eu.org | $0 | 碰运气 | 备选（抽奖级） |
| GitHub 学生包 .me | 首年 $0，续费 ~$23.98/年 | 在读学生 | 专区 |
| DigitalPlat | $0 | — | 不上 |

**坑点重申**：① 共享子域名随时可能被域名所有者撤掉，选官方自持的 mooo.com 类；② Google 默认不收录共享子域名，别指望 SEO；③ 滥用（spam/违法 host）会被单点封锁，政策透明，正常用没事。
