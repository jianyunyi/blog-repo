# 一个账号白嫖几十个大模型：腾讯云 TokenHub 新人 100 万 Token 全攻略

腾讯云 TokenHub 的新人包适合一句话概括：一个账号，能给几十个模型各领 100 万 Token——DeepSeek、GLM、Kimi、混元等多个模型的 API 一次领齐，跑通调用链路、做对比、做小项目都够用；但活动截至 2026-12-31，额度自领取起 1 年内有效，想零花钱就别开后付费。

> 最后核实：2026-11-03
> 官方来源：腾讯云 TokenHub 计费文档 https://www.tencentcloud.com/zh/document/product/1300/80423
> 领取前请以控制台实际页面为准，活动规则以页面公告为准。

## 一句话结论

腾讯云 TokenHub 的新人包，适合一句话概括：**一个账号，能给几十个模型各领 100 万 Token**。不是只给一个模型试用几天，而是把 DeepSeek、GLM、Kimi、混元等多个模型的 API 一次领齐，拿来跑通自己的调用链路、做对比、做小项目都够用。

但它有两个硬边界，必须先说清楚：第一，**本期活动截至 2026-12-31**，过期不候；第二，**额度自领取起 1 年内有效**，过期自动失效。也就是说，12 月底之前领，额度可以用到 2027 年底；拖到活动结束后再去，就没有了。

## 今天能领到什么

- **语言模型：每模型 100 万 Tokens。** 每个账号、每个模型仅可领取一次，调用时优先消耗免费额度。
- **多模态理解模型：同样是每模型 100 万 Tokens**，规则与语言模型一致。
- **视觉 / 3D 相关免费包：** 调研中提到另有 HY-3D 各 100 积分等包，具体模型和积分数以领取页实际显示为准，不要凭印象领。

换句话说，价值不在“一个模型给得多”，而在“模型给得全”。你想对比 DeepSeek 和 GLM 写代码的效果，或者想试 Kimi 的长文本，不用每个平台各注册一遍，在 TokenHub 里一次领齐。

## 领取步骤

1. **注册并登录腾讯云账号**，完成账号实名。实名是调用 API 的前置条件，没有实名领了也调不通。
2. **进入 TokenHub 的免费额度 / 新人包页面**，找到你要用的模型，逐个领取。注意：是按模型领，不是按账号一键全领。
3. **只领近期要用的模型。** 官方文档原话的精神就是这个：不要把所有模型一口气领完。为什么？因为每个模型只能领一次，额度又有 1 年有效期。现在领了、用不上，等于把 1 年倒计时白白开走。正确做法是：这周要试哪两个，就领哪两个；下周要试新的，再去领新的。
4. **创建 API Key**，记下 Key 和对应模型的调用地址。Key 只显示一次，丢了就重新创建，不要把 Key 贴到公开仓库、群聊或截图里。
5. **先跑一次最小调用**，确认额度在消耗、返回正常，再写进自己的项目。最小调用示例（以 OpenAI 兼容接口为例，实际地址和模型名以控制台文档为准）：

```bash
curl https://api.example.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-v4-pro", "messages": [{"role": "user", "content": "用一句话介绍 TokenHub"}]}'
```

注意：上面地址是示意写法，**不要直接复制去跑**，一定要用控制台给你的真实 Base URL 和模型名替换。

## 额度怎么算，别算错

- 100 万 Token 是按模型算的，不是按账号汇总的。A 模型用完 100 万，不影响 B 模型剩下的 100 万。
- 调用时优先扣免费额度，免费额度扣完才轮到付费——前提是你开了后付费。这一点下面坑点会再说。
- Token 消耗包括输入和输出。写长提示词、让模型输出长文章，都会加速消耗。做对比测试时，先用短提示词验效果，再放大用量。

## 三个坑，领之前必须知道

### 坑 1：不要开后付费，如果你想零花钱

免费额度用完后，**如果你没有开启后付费服务，调用会自动停止**；如果你开了，就会开始按量计费。所以，想做到真正的零花钱，做法很简单：**不要开后付费**。等免费额度用完，停下来换下一个模型，或者等下一个活动，而不是让账单悄悄跑起来。

反过来，如果你确实要长期用、愿意付费，那就另当别论，但那就不是“白嫖攻略”了，预算要自己先算好。

### 坑 2：只领要用的，别贪多

每个模型只能领一次，额度 1 年有效。一次性把几十个模型全领了，看起来很爽，实际上大部分模型一年内根本不会碰，等于浪费领取机会。按需领取，才是把 100 万 Token 用出价值的办法。

### 坑 3：不要写“领取时冻结 10 美元”

调研中提到，此前有二级说法称“领取时冻结 USD 10”，但**本次实读的官方文档里没有出现这一条**，所以本稿不写这一条。领取时控制台如果真的有提示，以控制台实际提示为准，不要把二级说法当成官方规则写进教程。

## 适合谁，不适合谁

- **适合：** 想一次对比多个模型的人；想跑通 API 调用链路、做小工具、做 Agent 原型的人；不想为每个模型各注册一个账号的人。
- **不适合：** 只想用某一个模型、且该模型在别处有更长期免费档的人；需要大并发、高稳定性的生产环境——免费额度不是为生产扛量设计的，超量会停，生产要用付费档。

## 和同类免费接口怎么选

本站 2026-11-02 的 Pollinations 免费接口文，是另一条免费路线：免注册、随用随调，适合快速试效果。TokenHub 的优势是模型多、额度按模型给，适合认真对比和长期做项目；劣势是需要注册实名、按模型领取。两条路线不冲突：快速试用走 Pollinations，认真做项目走 TokenHub。
