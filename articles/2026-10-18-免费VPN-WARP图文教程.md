# 免费 VPN：Cloudflare WARP，无限流量一键加密上网

> 一句话导读：Cloudflare 官方出品的免费加密上网 App，不用注册、没有流量上限，手机电脑装上一点就连——10-16 那篇讲的是 Proton 免费版（有节点限制），这篇是真正"装完即用"的 WARP。

## 前置条件（需要什么）

- 一部手机或一台电脑（Windows / macOS / Linux / iOS / Android 全支持）
- 不用注册账号，不用绑卡，全程 $0

## 分步骤

### 步骤 1：认准官网，别下到山寨 App

官网是 https://one.one.one.one/（Cloudflare 官方），首页写明 "The free app that makes your Internet safer"。手机去 App Store / Google Play 搜 "1.1.1.1: Faster Internet"（开发商 Cloudflare），电脑点官网的 macOS / Windows / Linux 下载按钮。

![1.1.1.1 + WARP 官网首页](img/2026-10-18-免费VPN-WARP/step1.png)

### 步骤 2：安装（以 macOS 桌面端为例）

按官方文档走：下载 Cloudflare WARP 安装包 → 打开 `.pkg` → 按指引完成安装（装完自动出现在菜单栏）→ 选择 Next 并接受隐私政策。Windows 版注意需要 .NET Framework 4.7.2 以上，Win10/11 自带一般没问题。

![WARP macOS 官方安装步骤](img/2026-10-18-免费VPN-WARP/step2.png)

### 步骤 3：打开大开关，连接

手机端三步（官方文档原话）：打开 1.1.1.1 App → 接受服务条款 → 把 **WARP** 大按钮拨到 **Connected**，再按提示安装 VPN 配置文件。看到状态变"已连接"，你的流量就已经走 Cloudflare 加密隧道了。

### 步骤 4：验证 IP 真的变了

浏览器访问 `cloudflare.com/cdn-cgi/trace`，看 `ip=` 那一行——应该显示一个 Cloudflare 的出口 IP，而不是你宽带的真实 IP。这就成了。

### 步骤 5（可选）：只想加密 DNS，不想走隧道

App 里把 WARP 开关拨下 → 选 **Switch to DNS only mode**（或菜单里选 1.1.1.1 而不是 WARP）：只加密 DNS 查询，其余流量走直连，速度更快，适合只防 DNS 污染的场景。

## 注意事项、费用、坑点

- **费用**：基础版 WARP 免费、无流量上限、无需账号；WARP+ 是付费档，官方说法是"接入更大的网络、可能降低延迟"，免费版日常用完全够。
- **不能选国家**：WARP 出口是 Cloudflare 自动选的边缘节点，**不能指定美国/日本 IP，也解不了流媒体分区**——要看 Netflix 美区、注册分区限制服务，它帮不上忙。
- **关键区别（和你住宅 IP 项目相关）**：WARP 出口是**机房 IP**，风控系统一眼认出是数据中心流量，**不能替代住宅 IP** 做养号、广告开户这类业务。日常加密上网、防蹭网、加密 DNS 用它；要"像家庭宽带"的 IP，还是得走你 10-15 定下来的住宅代理路线。
- **隐私结构**：DNS、隧道、出口 IP 都在同一家美国公司手里，官方 1.1.1.1 解析器有过独立审计，WARP 隧道本身暂无公开的专项审计——防的是路上的人，不是对 Cloudflare 隐身。
- **前科排查**：Cloudflare 大厂服务，无"免费版突然收费/批量封号"黑历史；对比坑位：某些"永久免费 VPN"靠卖带宽或插广告回血，谨慎。
