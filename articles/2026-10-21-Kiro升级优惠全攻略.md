Kiro 是 AWS 出的 AI 编程 IDE。最近流传的说法是"首次升级白送一个月 Pro/Pro+"，不少人冲着这句话就去点了订阅。先把结论摆前面：**这不是"首月免单"，而是给首次升级的新用户一笔 $20 订阅抵扣，而且抵扣额和当月订阅费一样按剩余天数折算**。Pro（$20/月）当月基本能相抵；Pro+（$40/月）当月必然还剩约一半差额要付。这篇按 Kiro 官方文档把资格、算账、升级、取消四件事讲透，照着做不会被续费偷袭。

## 一、先确认资格：四条缺一不可

🔹 **必须是个人账号的首次 Free → 付费升级**：以前订过、取消后再订，不算首次，别指望再领一次；
🔹 **登录方式要对**：Google、GitHub 或 AWS Builder ID。企业用的 AWS Identity Center 组织登录不适用这个优惠，别把两种 AWS 登录搞混；
🔹 **Builder ID 不能已关联 AWS 账户**：官方写明只有未关联的 Builder ID 能走个人升级流程，升不了先查这条；
🔹 **要有效信用卡 + 受支持地区的真实账单资料**：官方只承诺信用卡，储蓄卡/预付卡不保证能用；别虚填地区绕限制。仅凭"我刚注册"不保证结账金额为零，一切以你的结账页为准。

## 二、算账：抵扣为什么不等于免单

两档给什么：Pro $20/月含 1,000 credits，Pro+ $40/月含 2,000 credits。credits 是用量单位、不是美元也不是固定提问次数，消耗看任务复杂度和模型倍率；升级立即拿到整月额度，但月度额度不结转。两档都能用付费模型——**不需要为了试某个模型去买 Pro+**，Pro+ 只是额度多。

折算算法（设 r = 当月剩余天数 ÷ 当月总天数）：当月订阅费 ≈ 套餐价 × r；当月抵扣 ≈ $20 × r。所以 Pro 当月两边相抵；Pro+ 当月还差约 $20 × r 要真金白银付。官方半月算例最能说明问题：6 月 15 日升 Pro，当月抵扣用掉 $10；**如果不取消，7 月 1 日会收 $20 月费、抵掉剩余 $10，实扣 $10**，之后恢复全额。也就是说这笔优惠是"跨月分着用"的，不是当月清零的免单券。按同理推算，半月升 Pro+ 当月税前仍需约 $10。

⚠️ 月底大坑：Kiro 按 **UTC 自然月**计费，每月 1 日进新周期，不是"订阅日起 30 天"。月底升级，当月可用时间所剩无几，下月 1 日转眼就到；不想续费就别拖到最后一天才处理。价格不含税，银行卡外币结算按发卡行规则——别拿"卡里没美元余额"判断不会扣款。另外 add-on credits 是单独付费，不在抵扣范围内，只想体验套餐额度就不要额外买。

## 三、升级步骤：核对完再点 Subscribe

1）官网下载安装 Kiro，用 Google / GitHub / Builder ID 登录（记住用的是哪种，之后浏览器管理页必须是同一个身份，光邮箱相同不算）；2）点个人资料图标 → **Upgrade Plan**；3）选档位——只为低成本体验优先 Pro；4）点 Open 在浏览器打开结账页；5）**点 Subscribe 之前**逐项核对：套餐名、月价、当月折算、抵扣、税费、最终应付总额和续费安排——抵扣可能只是按天折算后的一部分金额，别把 Subscribe 当成"验卡按钮"；6）金额符合预期才填支付资料提交，完成后点 Get started 返回 IDE；7）保留订阅确认/账单。页面转圈或状态不明时，先查已有订阅和账单，不要连点重试。

## 四、试 Opus 5.5：先看额度再跑

官方模型页写明 Claude Opus 5.5 向 Pro 及以上开放（Free 用不了），1M 上下文、计费倍率 2.0x、标为实验性支持。注意 2.0x 不是"一句话扣 2 credits"，复杂任务会多步执行、消耗远超直觉；1,000 credits 更不能直接换算成"能问 500 次"。正确姿势：先拿不含敏感信息的小项目试水（比如"先解释目录、给最小改动方案、先别动文件"），在用量页看 credits 实际消耗（官方说用量至少每 5 分钟才刷新一次），心里有数了再上正活。只为一个实验性模型盲目升贵档，不值。

## 五、取消续费：正式切回 Free，别耍小聪明

不必等月底：月中取消，当月付费权益保留到月末，下一周期转 Free、不再扣费（当月已发生的费用不退）。官方路径：个人资料图标 → **Manage Plan** → 浏览器里选 **Update subscription** → 选 **Kiro Free** → Continue → 核对降级内容与生效时间 → **Confirm** → Return to Kiro。完成后保存降级确认页面或邮件；当月仍显示 Pro 是正常现象，判断标准是"未来计划已安排切回 Free"。反过来，**不往卡里放钱、清空余额、卸载 App、退出登录——没有一样能代替取消**，订阅状态不会因为一次扣款失败自动变 Free。

## 六、常见卡点速查

🔹 结账页没优惠/金额非零：先查是否首次升级、登录方式对不对，再分清 Pro 与 Pro+、抵扣是否已按天折算、税费多少；Pro+ 有差额通常不是错误；
🔹 找不到 Upgrade Plan：查 Builder ID 是否已关联 AWS 账户；已升过级的账号 IDE 不再显示首次升级选项，走 Manage Plan 管理——但这不代表能再领一次首次优惠；
🔹 升级后仍显示 Free / 看不到 Opus 5.5：先对齐浏览器与客户端的登录身份，再确认订阅已生效、客户端版本与官方模型列表；地区与实验性调整也会影响可见性，别为此重复购买；
🔹 额度掉得快：倍率 + 复杂任务是主因，到顶后别把买 add-on 当免费续命，先确认自己是否已安排切回 Free。

Subscribe 前最后五查：资格✓、结账页真有优惠✓、没把 Pro+ 当免单✓、看清当月应付与续费安排✓、会走正式取消路径✓。五条全过，再点下去。
