# 免费域名还没死：乌克兰 pp.ua 申请实录，0 元拿下、还能年年免费续

> 一句话导读：Freenom 倒了之后，乌克兰的 pp.ua 是硕果仅存的"真·免费域名"——nic.ua 官方通道 0 元注册、0 元续费，全程不用出国；代价是你要过三关：邮箱验证、绑银行卡、手机号短信激活。本篇把三关一步步拆开讲。

## 先说结论：2026 年还能办吗？

能。根据 NIC.UA 官方知识库（2026 年仍在更新维护的文档），pp.ua 免费注册通道依然开放，官网首页至今还在推"Free pp.ua Domain"。但它和以前的 Freenom 完全不是一个路子：**pp.ua 的"免费"是有条件的**——注册局用"邮箱验证 + 绑定银行卡 + 手机号短信激活"三道关来挡机器人和批量注册。你过得了三关，域名就是你的；过不了，订单会一直卡着不执行。

另外先泼一盆冷水：pp.ua 适合做测试站、个人博客、作品集、落地页验证想法，**不建议挂正式收款业务**——免费域名的观感问题，以及 WHOIS 信息强制公开（见下文），做生意还是买付费域名。

## 前置条件（动手前备好这 4 样）

1. **一个邮箱**：Gmail、Outlook 都行，注册 nic.ua 账号用，还要收验证信。
2. **一张银行卡**：Visa / Mastercard 的借记卡或信用卡都行。只做身份验证，官方明确"免费服务依然免费"，不会扣费。这是挡批量注册的"人机验证"，不是付款。
3. **一个能收短信的手机号**：注册局会发激活码短信。官方文档没说必须是乌克兰号码；但有 2021 年的实测记录提到，非乌克兰号码收短信可能不稳定——**备选方案是走 Telegram 机器人 @ppuabot**，用同一个手机号注册的 Telegram 账号即可。
4. **一个 Telegram 账号**（强烈建议提前装好）：短信收不到时的兜底激活通道。

费用：**nic.ua 官方通道注册 0 元、续费 0 元、转出 0 元**。注意：pp.ua 注册局允许注册商自行定价，有些乌克兰本地注册商会收服务费（比如 Cityhost 收约 49 格里夫纳/年），所以认准从 nic.ua 官方走。

## 步骤一：先看懂 pp.ua 的游戏规则

动手前先去 nic.ua 官方知识库看一眼《PP.UA domains restrictions》，把限制条件刻进脑子里，免得踩坑：

![nic.ua 官方知识库：PP.UA 域名限制说明页](img/2026-10-22-ppua-domain/step1.png)

核心规则就四条，官方原文，我翻译成人话：

1. **域名必须激活才能用**：注册局会往你填的手机号发短信验证码，凭码去注册局网站（或 Telegram 机器人）激活。**续费时也要重新激活一次**。手机号换了要记得发邮件给 support@nic.ua 更新，否则续费收不到码。
2. **WHOIS 信息强制公开**：持有人姓名、邮箱等按注册局规定公开，**不能隐藏**，而且必须填真实准确的信息。乱填的后果：注册局有权把域名设为 serverHold 直接停解析。
3. **续费只能在到期前 4 个月内操作**：提前续不了，续费按钮是灰的。这是注册局的规定，不是 nic.ua 的 bug。
4. **一个手机号 30 天内最多注册 3 个**：注意是"提交订单"就计数，哪怕你最后没激活、订单被关了，也算用掉一个名额。想多拿就用第二个手机号。

域名长度 3–63 个字符，支持拉丁字母和西里尔字母（IDN）。注册期限最长 1 年——到期免费续，等于可以一直白嫖。

## 步骤二：注册 nic.ua 账号，完成"两件套"

打开 [nic.ua](https://nic.ua)（有英文版），注册账号。免费订单要执行，必须同时满足两个条件（官方知识库《How to activate PP.UA domain》原文）：

![nic.ua 官方知识库：免费订单的两个前置条件——邮箱验证与绑定银行卡](img/2026-10-22-ppua-domain/step2.png)

1. **验证账号的联系邮箱**：注册后去邮箱点验证链接。没验证，免费订单根本不会被处理。
2. **绑定一张银行卡**：在下单时账号里必须已绑卡。官方原话："Linking the card is only required for identification purposes; all free services remain free."（绑卡仅用于身份识别，所有免费服务依然免费。）

然后在 nic.ua 搜你想要的 `xxx.pp.ua`，有货就加入购物车下单，金额 0 元。订单提交后，注册局侧的请求**只有 5 天有效期**——5 天内不激活，请求作废、域名释放，你得重新下单。

> 坑点提醒：如果订单一直没动静，先自查这三样：邮箱验证了没？绑卡了没？同一个手机号 30 天内是不是已经下了 3 单？官方排障文档把这三条列为最常见原因。

## 步骤三：5 天内去注册局激活（最关键的一步）

下单 ≠ 拿到域名。**不激活，域名是 pendingCreate 状态，解析不了，5 天后被删。**

激活地址是注册局官网的表单：https://apu.drs.ua/en/ ，填三样东西——域名、手机号、短信验证码：

![pp.ua 注册局（DRS）域名激活表单：填域名、手机号和短信验证码](img/2026-10-22-ppua-domain/step3.png)

两种拿码方式：

- **短信**：注册局只发一次短信，填单时手机号务必写对（国际格式）。收不到就走下面这条。
- **Telegram 机器人**：在 Telegram 里搜 **@ppuabot**，点 Start，按"Send phone number"发送手机号（**必须是注册域名时填的同一个号码，且 Telegram 账号就注册在这个号码上**），选 "Activate domain"，输入域名（不带 www 和 http），同意 pp.ua 的域名规则，机器人会生成激活码。拿着码回到上面的表单提交。

激活成功后，域名状态变正常，就可以去 nic.ua 面板里改 NS / 加 DNS 记录，把域名指向你的服务器或 Cloudflare。有 2021 年的实测记录确认可以在 nic.ua 面板里把 NS 换成 Cloudflare 的（免费版 Cloudflare 照常用）。

## 续费：每年一次，别睡过头

- 续费免费，但**只能在到期前 4 个月（112 天）内**操作，按钮提前是灰的，别慌。
- 续费下单后**必须再激活一次**（同样收短信/走 Telegram），不激活等于没续，注册局侧的到期日不会变。
- 建议在日历上设两个提醒：到期前 3 个月（去续费），到期前 1 个月（确认激活成功）。

## 注意事项、费用、坑点汇总

| 项目 | 情况 |
|---|---|
| 注册费 | 0 元（nic.ua 官方通道） |
| 续费 | 0 元/年，需在到期前 4 个月内操作 + 重新激活 |
| 绑卡 | 必须，Visa/Mastercard，用于身份验证，不扣费 |
| 手机号 | 必须，用于收激活码；非乌克兰号码短信可能不稳，Telegram 机器人兜底 |
| 数量限制 | 同一手机号 30 天内最多 3 个域名 |
| WHOIS | 强制公开，不能隐藏，信息必须真实 |
| 适用场景 | 测试站、个人博客、作品集、落地页验证；不建议正式收款业务 |
| 风险 | 乱填资料会被 serverHold 停解析；5 天不激活订单作废 |

最大的坑其实是心态：pp.ua 的免费是"有门槛的免费"，三道关（邮箱、绑卡、手机激活）每一道都是为了挡住批量注册的机器人。你是真人，正常走流程，一次就能过。
