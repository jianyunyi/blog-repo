# 免费域名：is-a.dev 开发者子域名，GitHub 提个 PR 就拿下

> 一句话导读：yourname.is-a.dev 这种看着像正经域名的免费子域名，开发者凭 GitHub 账号提个 PR 就能注册，还能顺手薅个 DuckDNS 免费动态域名给家里/VPS 做远程访问。

## 前置条件（需要什么）

- 一个 GitHub 账号（免费注册）
- 一个要指向的地方：GitHub Pages / Vercel / Cloudflare Pages 项目，或者你 VPS 的 IP
- 全程 $0，无需信用卡

## 分步骤

### 步骤 1：先上 is-a.dev 查名字有没有被占

打开 https://is-a.dev，首页就有子域名可用性查询。规则：2–64 个字符，只能小写字母、数字和短横线。想好名字：名字、项目名都行，比如 `suhua.is-a.dev`。

![is-a.dev 首页与子域名查询](img/2026-10-18-免费域名-isadev/step1.png)

### 步骤 2：Fork 官方注册仓库

打开 https://github.com/is-a-dev/register，点右上角 **Fork**，把仓库复制到你自己账号下（只复制 main 分支就行）。

![is-a-dev 注册仓库](img/2026-10-18-免费域名-isadev/step2.png)

### 步骤 3：在 domains/ 目录下新建你的 JSON 文件

在你 Fork 来的仓库里进 `domains/` 目录，**Add file → Create new file**，文件名就是你要的子域名，比如 `suhua.json`（对应 `suhua.is-a.dev`）。内容按官方模板填：

```json
{
  "owner": {
    "username": "你的GitHub用户名",
    "email": "你的邮箱"
  },
  "record": {
    "CNAME": "你的GitHub用户名.github.io"
  }
}
```

- 指向 GitHub Pages 就用上面的 CNAME 写法
- 指向 VPS 直接写 A 记录：`"record": { "A": ["你的服务器IP"] }`
- 支持的记录类型很全：A / AAAA / CNAME / MX / TXT / URL 跳转，玩邮箱验证、301 跳转都够用

![register 仓库的 domains/ 目录：每个子域名就是一个 JSON 文件](img/2026-10-18-免费域名-isadev/step3.png)

上图是仓库里真实的 `domains/` 目录——一万多个 JSON 文件，每个对应一个已注册的子域名，最新合并 9 分钟前，系统活着。

### 步骤 4：提交 PR，等合并

Commit → Push → 回到你 Fork 的仓库点 **Compare & pull request**，按 PR 模板填好信息提交。**关键**：勾选 "Allow edits from maintainers"，能让维护者直接帮你改小问题，加速通过。维护者一般几小时到 72 小时内审核，通过后自动合并，DNS 几分钟内生效，浏览器打开 `你的名字.is-a.dev` 验证。

### 步骤 5（备选）：DuckDNS 免费动态域名，给机器做远程访问

如果你的需求是"随时连到家里电脑/VPS"，而不是"好看的网址"，用 https://duckdns.org：GitHub 账号一键登录，免费领 `xxx.duckdns.org`，IP 变了自动更新。家里宽带、Oracle VPS 建好后做 SSH 远程访问都用得上。

![DuckDNS 免费动态 DNS 首页](img/2026-10-18-免费域名-isadev/step4.png)

## 注意事项、费用、坑点

- **费用**：$0，Cloudflare 赞助 DNS 基础设施，无广告、无数据收割。
- **这不是"你的"域名**：子域名的 DNS 控制权在 is-a.dev 社区手里，适合作品集、演示站、个人项目；正式做生意的品牌站还是建议买个正经域名（10-16 的 afraid.org 篇是另一路免费子域名，可对照看）。
- **PR 审核要点**：项目须和开发相关，填表别糊弄；被打回就按意见改，拖着不回会被拒。
- **NS 委托限制**：想把整个子域名的 nameserver 委派出去（NS 记录）只在特殊批准情况下允许，且子域名需存在 30 天以上。
- **前科排查**：is-a.dev 持续运营多年，2026 年仍在正常接受注册（多篇 2026 年实测教程可证）；同类已死名单：Freenom（.tk/.ml 全灭）、360hitao 转运（2023 年停运，非域名但同属"免费"坑位）。
- **HTTPS**：GitHub Pages / Cloudflare Pages / Vercel 那头开 "Enforce HTTPS"，免费证书自动配好。
